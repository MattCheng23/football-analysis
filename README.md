1. **新会话开工**：读 `pre-match-analysis`/`batch-pipeline` 技能（~/.agents/skills）→ 速查表 → 权威模型 V11.34
2. **看今天预测**：发布网站 → 按日历选批次
3. **查历史结果**：`04_赛果数据\赛果台账_*.md` + 网站复盘页
4. **规则怎么来的**：`01_当前模型\流程体检优化清单_20260905.md`（四路体检）+ `02_模型记忆\历史版本_定稿与旧方案\`（每版蒸馏记录）
