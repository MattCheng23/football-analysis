## 二、7 条核心原则（不可动摇）

| 原则 | 内容 |
|------|------|
| P1 | 方向决定全场——胜/平/负严格对应主客进球大小关系 |
| P2 | 比分必须匹配方向——TOP3 全部指向同一全场结果 |

| P4 | 交叉校验强制执行——方向→比分TOP1→半全场TOP1 三者一致 |

| P7 | 赛后复盘禁止修改预测，偏差→转规则→下一轮生效 |
