📜 模型核心（V10.29-Fix-R4）

七条核心原则

原则内容
P1方向决定全场——胜/平/负严格对应主客进球大小关系
P2比分必须匹配方向——TOP3 全部指向同一全场结果
P3半全场第二字必须匹配方向
P4交叉校验强制执行——方向→比分TOP1→半全场TOP1 三者一致
P5完全不参考盘口——禁提任何亚盘/水位/升盘降盘（黑名单自动检查）
P6规则必须基于 ≥50 场历史数据，禁止单场补丁式规则
P7赛后复盘禁止修改预测，偏差→转规则→下一轮生效

演戏识别规则（R314 / R321-R328）

编号名称识别逻辑
R314控盘放水丢球识别2-0 领先 + ≤5 分钟连丢 2 球 + 对手保级 → 平局 +20%
R321野鸡赛不可预测系数小联赛主场强队排名高 ≥4 位却输球 → 标记"演戏嫌疑"
R322闪击后收工识别开场 ≤5 分钟进球 → 半场前无第 2 球 → 下半场预期 -0.5 球
R323安慰球识别落后 ≥3 球后 75' 后的进球权重降低 50%
R324射门转化率倒挂预警一方 >30% 且对手 <15% → 标记"效率异常"
R326碾压收窄识别（新）射门 ≥2.5 倍 + 射正 ≥2 倍 + 85' 后连丢 ≥2 球 → 赢球放水标记（012 实证）
R327占优惨败识别（新）控球 ≥55% + 角球领先 + 射正持平却输 ≥2 球 → 演戏嫌疑（002 实证）
R328半场领先收缩预警（新）半场净胜 ≥2 球但射正持平 + 下半场丢 ≥2 球 → 控制力骤降（009 实证）
