## 二、评级层（纯 ABC 三档，2026-08-21 用户重申）

| 等级 | 标准 | 比分结构 |
|---|---|---|
| A | **R393 达实力差距**（排名差≥6 / H2H 碾压·连续不败·克星 / 身价差 5 倍 / 卫冕冠军）且**无重大风险**（避雷🔴/剧本场/核心伤停≥3无替代/门将停赛）；R379 轻微因素（首轮/小伤/天气/客队韧性/德比变数/揭幕期）**不降级**；R387 红榜通道（⭐R2+优势维度≥2）亦可达 A | 3 正路、**自信单选方向**（无平局占位） |
| B | 中置信统一档：有优势非碾压 / 接近场 / 平局信号触发双选 | 2正1反（反向仅红黑榜导向） |
| C | 低置信高风险野鸡场 | 1正2反 |

**要点**：
- 废除 A+/A-/B+/B- 细化（全量实证负优化）；**禁止连降两级**（A→B 只能因重大风险一项）
- 评级对了，比分结构自动对（B 级双选+平局代表会挤掉正路大比分——评级过严审计 12 场实锤）
- 五大联赛战意值不低估（争冠/欧战/保级每分关键，初期演戏少 R359 但求胜欲强）
- 用户核心洞察：**评级是五维之首，评级错则比分结构系统性错**

## 四、比分层（方法论 v4 定稿，2026-08-22 用户四轮修正）

**完整判定链**：
1. **λ基线**：λ和 <2.2 小 / 2.2-2.6 看攻防画像 / ≥2.6 大
2. **攻防画像**：弱队攻击全残→**零封打穿局**（20/30/40 系含客队镜像）；强攻+对手防线漏→**漏勺局**（30/31/40/41 系）；双方难进球→**小球均势**（10/11/01/21/20/12/02）；双方攻击端都在+防线都漏+杯赛放开打→**对攻双向**（22/31/32/23/42/24 甚至 7+，**禁止用零封形态替代**）
3. **剧本修正**：避雷/剧本场控场小比分领先不多；德比/杯赛/雨/高温降档
4. **大小球只是参考不是锁死范围，最终按最合理比分**（考虑全部因素）
5. **A 级=自信单选方向**（比分 TOP3 全主方向无平局占位）

**硬约束**：
| 规则 | 内容 |
|---|---|
| R392 | λ和 ≥2.4 → TOP3 至少 1 项 ≥4 球（2.4-3.0 是漏大球高发区） |
| R390 | 双向净胜档：主胜≥2 形态必覆盖净1+净2；客胜同理；λ主≥1.2 且客攻击弱→2-0 与 1-0 并列 |
| R374 | 平局代表让位：双选场主方向队火力强（近3场≥3球）→ 1-1 让位主方向大比分（平局由 ht 平平+alerts 覆盖） |
| R348 | 日职/韩职比分默认含 ≥4 球项（高进球联赛惯性） |
| R380-383 | 欧战首回合必含打穿项 / 主强+客锋伤疑→零封大胜并列 / R370 与反向冲突时反向优先 / H2H 近3次同比分≥2 次强制进 TOP3 |
| P9 | 泊松天然保守偏小分，禁止优化回保守值（把 3-1 改 1-0 是错误方向） |

**进球属性声明**：每场 logic 必写「**进球属性：小球局/大球局（依据）**」——检查工具豁免机制的基础。

## 六、总进球层（2026-08-22 用户拍板：参考比分联动，替代 8/17 独立判定）

**总进球跟着比分走，比分不被总进球反推**（先比分后 ou）。执行口径：

| 比分球数 | ou 档 |
|---|---|
| 全 ≤2 球 | 1·2 |
| 含 3 球无 ≥4 | 2·3 |
| 含 4 球 | 3·4 |
| 含 5+ 球 | 4·5 |

- 单 4 球覆盖项（R392 强制如 2-2 大球平局）可保持主档 2·3，需 logic 写明 R392
- R394 兜底：λ和 ≥2.2 → ou 禁 1·2 档（至少 2·3）
- R386 参考：任一方近 10 场 over 2.5≥70% / 防线残阵 / 对攻画像 → 档位+1；场地压制/战术克制/核心锋线缺 → 档位-1；λ 两档并列取高档
- check_batch_full 6j 自动校验（含 3 球项分支）

## 九、情报流程（2026-08-22 用户拍板最优流程）

**每个新批次赛前必做**：
1. 提取本批全部场次预测摘要（方向/评级/比分/ht/ou/λ/logic 全文）
2. 派 4-5 个子代理并行联网核查（每组 4-6 场；prompt 含每场当前预测全量+核查维度+评级规则 R393/比分规则 R392+输出格式；web_search 配额耗尽时用 read_page 直读 sportsmole 等）
3. 主代理自查关键场（A 级场核心变量：核心球员状态/新帅/新援/欧战夹心）
4. 合并修正清单（唯一子串替换 gen_sat_batch.py 单源）
5. 全量校验（check_batch_full+run_all_checks+audit）
6. 部署（bump_version→wrangler→专属 URL 验证）

**情报使用铁律（2026-08-22 用户拍板）**：
- **子代理只负责提供信息，不能替你判断**——它没有主代理优化的多（方法论/规则积累）；"修正建议"只是参考，最终判断按完整方法论+用户拍板优先级
- **情报参考优先级：伤停因素、历史交锋优先；天气必须取比赛时间点（开赛当地时刻）实测**（open-meteo hourly/FotMob 开赛时点），不能取当日峰值
- 子代理情报必须多方面核查保证真实（sportsmole/sportsgambler/网易/FotMob/open-meteo/whoscored 多源交叉）
- 用户拍板过 ≠ 不能改——有新证据（多源核实）时按证据重新分析（001 实证：H2H 近5次 1胜3平1负+大球率20%+94% 雨 → 大球局改小球局）
- 中文源伤停强制查询（懂球帝/网易彩经/新浪/腾讯/搜狐/捷报多源交叉），传闻未证实不采纳
