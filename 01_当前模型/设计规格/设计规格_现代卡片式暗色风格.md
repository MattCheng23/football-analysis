# 足球赛事分析报告中心 · 现代卡片式暗色风格设计规格

> 风格对标：Linear / Vercel / Notion 类顶级 SaaS 产品界面。
> 目标：高信息密度（表格、KPI、风险标签）保持清晰可读，同时有精致设计感。

---

## 1. 设计理念

**深色为主（dark-first），浅色仅作可访问性备选。** 本产品是高信息密度的数据型页面（预测清单表格、命中率 KPI、风险等级标签），深色低饱和底色能让数据本身成为视觉主角、降低长时间阅读的眩光；Linear/Vercel 已验证"近黑底 + 微光边框 + 靛紫点缀"在专业数据产品上的表现力。浅色主题通过 CSS 变量一键切换保留，但默认与主推均为深色。

三条核心原则：
1. **表面层级代替色块**：用 `bg-page → bg-card → bg-elevated` 三层"面的明度差" + 1px 微光边框表达结构，不用粗边框、不用大色块。
2. **颜色只用于语义**：靛蓝主色仅用于交互焦点（排序、选中、按钮、链接）；绿/黄/红只用于命中、风险、预警；正文与结构一律灰阶。
3. **精致感来自细节而非装饰**：150ms 过渡、hover 抬升、玻璃拟态 sticky 头部、tabular-nums 数字对齐、渐变仅限标题与主按钮 3 处点缀。

## 2. 配色方案

### 2.1 深色主题（默认）

| Token | 色值 | 用途 |
|---|---|---|
| `--bg-page` | `#0A0B0D` | 页面底色（近黑、微冷调） |
| `--bg-card` | `#121316` | 卡片、面板 |
| `--bg-elevated` | `#17191D` | 悬浮卡片、下拉、菜单、弹层 |
| `--bg-hover` | `rgba(255,255,255,0.035)` | 行/项 hover 底 |
| `--border` | `rgba(255,255,255,0.08)` | 默认 1px 边框（微光边框） |
| `--border-strong` | `rgba(255,255,255,0.14)` | hover / 激活边框 |
| `--text-primary` | `#E6E8EB` | 标题、正文主文本 |
| `--text-secondary` | `#9CA3AF` | 次级文本、表头、说明 |
| `--text-muted` | `#6B7280` | 弱化文本、脚注、批次号 |
| `--accent` | `#6366F1` | 主色·靛蓝（按钮/排序/选中/链接） |
| `--accent-bright` | `#818CF8` | 主色 hover / 高亮 |
| `--accent-2` | `#22D3EE` | 辅助色·青色（数据趋势、指标数值、渐变端点） |
| `--success` | `#34D399` | 命中、达标、正常 |
| `--warning` | `#FBBF24` | 风险预警、高价值提示 |
| `--danger` | `#F87171` | 高风险、失败、避雷 |

**渐变主视觉**：`linear-gradient(135deg, #6366F1, #8B5CF6 55%, #22D3EE)` —— 仅用于：站名标题渐变字、主按钮、KPI 大数字、（可选）冷门风险卡顶部 3px 光条。

**阴影层次（深色）**：
- `--shadow-sm: 0 1px 2px rgba(0,0,0,.4)` —— 默认卡片
- `--shadow-md: 0 2px 4px rgba(0,0,0,.3), 0 8px 24px rgba(0,0,0,.35)` —— hover 卡片
- `--shadow-lg: 0 8px 16px rgba(0,0,0,.4), 0 24px 48px rgba(0,0,0,.45)` —— 弹层
- `--glow-accent: 0 4px 20px rgba(99,102,241,.35)` —— 主按钮/主元素发光

### 2.3 语义色的统一呈现法（关键）

所有状态色**不做纯色填充**，统一为 `color: 色值; background: 色值@12%; border: 1px solid 色值@28%`。醒目但不刺眼，是 Linear/Notion 的标准做法。

## 3. 字体方案（纯系统字体栈，零 CDN）

| 角色 | 字体栈 | 说明 |
|---|---|---|
| UI/正文（含中文） | `"Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", "Noto Sans SC", sans-serif` | 中文回退微软雅黑 |
| 数字/英文标题/KPI | `"Bahnschrift", "Segoe UI", "Microsoft YaHei", sans-serif` | Bahnschrift 为 Win10 自带展示字体，数字有科技感 |
| 等宽（批次号/版本号） | `"Consolas", "Cascadia Mono", "Courier New", monospace` | 如 V10.29-Fix-R5、数据指纹 |

**字号阶梯与字重**：
- KPI 大数字：34px / 600 / Bahnschrift / `font-variant-numeric: tabular-nums` / letter-spacing -0.01em
- 卡片标题：17px / 650
- 区块小标题：15px / 600
- 表格正文：13.5px / 400
- 表头与标签：12px / 600，letter-spacing 0.04em
- 注释/脚注：12px / 400，text-secondary 或 muted

**全局**：`font-variant-numeric: tabular-nums;` 保证表格数字逐列对齐（信息密度的关键）；`-webkit-font-smoothing: antialiased;`；正文行高 1.55–1.6。

## 4. 关键组件样式

### 4.1 顶部标题栏（玻璃拟态）

```css
position: sticky; top: 0; z-index: 100;
background: rgba(10, 11, 13, 0.72);
backdrop-filter: blur(14px) saturate(1.5);
border-bottom: 1px solid var(--border);
```

- 高度 60px，内边距 0 24px，内容区 max-width 1200px 居中
- 站名：18px / 700，文字渐变（`background: linear-gradient(135deg,#6366F1,#22D3EE); -webkit-background-clip: text; color: transparent`），emoji ⚽ 保留
- 副标题行：12px text-muted
- 右侧：作者徽章 + 主题切换按钮（40×40px、radius 10px、hover 时 bg-hover）

### 4.2 导航（分段控件 segmented control）

```
容器:  background: rgba(255,255,255,0.04); border: 1px solid var(--border);
      border-radius: 10px; padding: 4px; display: inline-flex;
选项:  padding: 6px 16px; border-radius: 7px; font-size: 13.5px; color: var(--text-secondary);
激活:  background: var(--bg-elevated); color: #fff; box-shadow: var(--shadow-sm);
```

比传统下划线导航更"产品化"。

### 4.3 卡片容器（核心）

```css
background: var(--bg-card);
border: 1px solid var(--border);
border-radius: 14px;                    /* 大卡片；内嵌小组件用 10px */
box-shadow: var(--shadow-sm);
padding: 20px 24px;
transition: border-color 0.15s, box-shadow 0.15s, transform 0.15s;
transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1);
```

- **hover**：`border-color: var(--border-strong); box-shadow: var(--shadow-md); transform: translateY(-1px);`
- 卡片标题行：17px/650 + 左侧 18px emoji 图标；标题下加 12px muted 的"口径说明"行（如"73 场口径 · 更新于 2026-08-15"）
- 重点卡（冷门风险 Top6）：`::before` 顶部 3px 渐变光条（`background: linear-gradient(90deg,#6366F1,#22D3EE); border-radius: 14px 14px 0 0; height: 3px;`）

### 4.4 数据表格（现代感表头 + 行交互）

```
圆角容器: border-radius: 12px; overflow: hidden; 外层叠 1px 边框
表头 th: font-size 12px; font-weight 600; letter-spacing 0.04em;
         color: var(--text-secondary); background: rgba(255,255,255,0.03);
         padding: 10px 16px; border-bottom: 1px solid var(--border); text-align: left;
单元格 td: 13.5px; padding: 12px 16px; border-bottom: 1px solid rgba(255,255,255,0.05);
行 hover:  background: rgba(99,102,241,0.07);   /* 靛蓝微染，不是纯白 */
可排序列: 表头 hover 变 accent 色 + 右侧 ▲/▼ 12px 图标；激活排序 color: var(--accent-bright)
数字列:  text-align: right; font-family: var(--font-display); font-variant-numeric: tabular-nums;
斑马纹(可选): tr:nth-child(even) { background: rgba(255,255,255,0.015); }
首列加粗 + 主文本色；风险列用徽章（见 4.5）
```

### 4.5 标签/徽章（风险等级 高/中/正常）

```
padding: 2px 10px; border-radius: 999px;   /* 胶囊 */
font-size: 12px; font-weight: 600; line-height: 20px; white-space: nowrap;
```

| 等级 | 文字 | 背景 | 边框 |
|---|---|---|---|
| 高 | `#F87171` | `rgba(248,113,113,0.12)` | `rgba(248,113,113,0.28)` |
| 中 | `#FBBF24` | `rgba(251,191,36,0.12)` | `rgba(251,191,36,0.28)` |
| 正常 | `#34D399` | `rgba(52,211,153,0.12)` | `rgba(52,211,153,0.28)` |

可选增强：`::before` 6px 同色圆点（间距 6px）——高风险徽章建议加，扫描速度更快。

### 4.6 按钮

```
主按钮: height 36px; padding 0 16px; border-radius: 8px;
        font-size 13.5px; font-weight 600;
        background: linear-gradient(135deg,#6366F1,#8B5CF6); color: #fff;
        hover:  filter: brightness(1.1); box-shadow: var(--glow-accent); transform: translateY(-1px);
        active: transform: translateY(0); filter: brightness(0.95);
次按钮: background: rgba(255,255,255,0.05); border: 1px solid rgba(255,255,255,0.1);
        hover: background: rgba(255,255,255,0.09);
幽灵按钮(主题切换等图标钮): 无底无框; hover: background: var(--bg-hover);
聚焦环: :focus-visible { outline: 2px solid rgba(99,102,241,0.6); outline-offset: 2px; }
```

### 4.7 附属组件（完整感）

- **KPI 数字卡**（命中率）：大数字 34px Bahnschrift + 渐变文字；标签 12px muted；涨跌 `▲ +2.1%` 用 success / `▼` 用 danger
- **日历（可折叠）**：日格 32×32px、radius 8px；hover bg-hover；选中 `background: rgba(99,102,241,0.16); border: 1px solid var(--accent)`；今日加 accent 小圆点
- **返回顶部**：40×40px 圆钮，bg-elevated + 边框，hover 发光
- **滚动条**：`::-webkit-scrollbar{width:10px;height:10px}`；thumb `rgba(255,255,255,0.12)` radius 5px，hover 提亮
- **页脚**：上边框 var(--border)，12px muted；免责声明用警告色调容器 `background: rgba(251,191,36,0.08); border: 1px solid rgba(251,191,36,0.2); border-radius: 10px; padding: 12px 16px`

## 5. 布局细节

- **间距节奏**：4px 基准，阶梯 4/8/12/16/20/24/32/48；卡片之间 20px，卡片内 20–24px
- **页面容器**：max-width 1200px，水平 padding 24px（≤768px 降为 16px）
- **z-index 层级**：sticky 标题栏 100 → 导航 90 → 返回顶部 80 → 弹层 200
- **栅格**：KPI 区 4 列 grid（≤1024px 2 列，≤640px 1 列）；冷门风险卡 3 列（≤768px 1 列）；表格容器 `overflow-x: auto` + `min-width` 防挤压
- **视觉动线**：标题栏（身份）→ KPI（结论）→ 日历（入口）→ 预测清单表格（主内容）→ 冷门风险/高价值预警（重点提示，警示色 + 光条强化）
- **主题切换实现**：`:root` 放浅色变量、`html.dark` 覆盖为深色；`html { color-scheme: dark }`；body 加 `transition: background-color 0.2s, color 0.2s`
- **对比度底线**：主文本 ≥ 7:1，次级 ≥ 4.5:1（`#6B7280` 在 `#0A0B0D` 上约 4.6:1，可作 muted 下限）

## 6. 与"极简数据终端"风格最大的 3 个区别

1. **表面层级 vs 单色平面**：数据终端是黑底+绿字、无边框无圆角，靠"字符亮度"表达全部信息；本方案用三层背景明度（page/card/elevated）+ 1px 微光边框 + 14px 圆角 + 层次阴影构建"物理层级"，结构一眼可读，卡片可悬浮抬升。
2. **语义色彩系统 vs 单色字符**：终端几乎单色，风险只能靠文字；本方案建立 accent/success/warning/danger 四色语义体系，以"12% 底色 + 28% 边框 + 高饱和文字"呈现——颜色本身成为第二套编码，高/中/正常、命中/预警 0.3 秒内可扫描。
3. **精致动效与玻璃拟态 vs 零反馈**：终端无 hover、无过渡、无层次变化；本方案有 150ms 缓动过渡、卡片 hover 抬升、sticky 玻璃拟态标题栏（blur+saturate）、分段控件导航、主按钮渐变发光、focus-visible 聚焦环、tabular-nums 数字对齐——这些"非必要但存在"的细节正是 SaaS 质感与终端质感的根本分界。

## 附：落地建议

全部以 CSS 自定义属性（变量）实现，主题切换只改变量；渐变与玻璃拟态各限 3 处以内；深色为默认与主推。可直接按本规格对照现有 `style.css` 逐项替换。
