## 方案 A · 传统体育门户风格（懂球帝/ESPN 系）

- **理念**：信息优先 + 编辑感，报纸头版式可信感，拒绝装饰特效
- **配色**：主色体育红 `#C8102E`（hover #A50D24 / active #8C0A1E / 浅底 #FBEDEE）；辅助藏蓝 `#1F4E79`、金黄 `#C99400`；页面背景 `#F2F3F5`、卡片 `#FFF`、顶栏 `#1F232B`；成功 `#1E8E3E`、警告 `#D97706`
- **深色主题**：红 `#E5484D`、绿 `#30A46C`、金 `#FFB224` 等
- **字体**：微软雅黑/Segoe UI，数字 Bahnschrift + tabular-nums；14px 基准（H1 24 / H2 18 / 表格 13 / 徽章 12）
- **组件**：56px 深色顶栏 + 4px 红顶条 + 红色方块 logo + 3px 红下划线激活态；卡片 6px 圆角 + 1px 边框 + 2px 轻阴影 + 红竖条标题；表格双线表头 + 极浅斑马纹 + 行 hover 红条；六类徽章（高/中/正常/已核验/高价值/冷门）实心/描边两级
- **布局**：max-width 1200px，12 列栅格三档响应式

## 方案 B · 极简数据终端风格（Bloomberg/TradingView 系）

- **理念**：装饰归零（无渐变/阴影/大圆角，圆角封顶 2px），层级全由 1px 边框 + 底色差承担；数字与表格是视觉主角
- **配色（双主题变量）**：
  - 深色：`--bg #0B0E13` / `--card #10141B` / `--border #1E2733` / `--ink #E6EBF2` / `--accent #FF8A1F`（终端橙）/ `--success #2EB77E` / `--warning #E8B44A` / `--danger #E5534E`
  - 浅色：`--bg #F1F3F6` / `--card #FFF` / `--border #DCE2E9` / `--ink #1B2430` / `--accent #B25E00` / `--success #177A52` / `--warning #9A6A00` / `--danger #C93A3E`
- **纪律**：语义色只以 11px 标签、6px 色点、行首 2px 边条出现，占比 <2%
- **字体**：正文 Segoe UI/雅黑；数字 Bahnschrift + tabular-nums；终端元素 Cascadia Mono/Consolas 11-12px；字号 11→12→13/14→26-28px(KPI)
- **组件**：40px 终端标题栏（`▍FTBL>` mono 前缀）；卡片 1px 边框 + 2px 圆角 + 无阴影；表格 30px 行高、sticky 表头、数字列右对齐+等宽、风险行 inset 2px 色条；徽章 11px + 6px 圆点 + 12% 底 + 35% 边框；主按钮橙色底近黑字 30px 高；120ms 过渡

## 方案 C · 现代卡片式风格（Linear/Vercel 系）✅ 已落地

- **理念**：dark-first 深色为主（浅色保留切换）；三层表面层级（page→card→elevated）+ 1px 微光边框 + 靛紫点缀；精致感来自细节而非装饰
- **配色**：深色底 `#0A0B0D` / 卡 `#121316` / 悬浮 `#17191D`；边框 `rgba(255,255,255,0.08)`；主色靛蓝 `#6366F1`、辅助青 `#22D3EE`；成功 `#34D399`、警告 `#FBBF24`、危险 `#F87171`；渐变 `#6366F1→#8B5CF6→#22D3EE` 仅限站名/主按钮/KPI 数字 3 处
- **语义色呈现**：统一"12% 底 + 28% 边框 + 高饱和字"
- **字体**：正文 Segoe UI/雅黑；数字 Bahnschrift + tabular-nums；等宽 Consolas；字号 12/13.5/15/17/34
- **组件**：sticky 玻璃拟态标题栏（blur 14px + saturate 1.5）；卡片 radius 14px + 双层阴影 + hover 抬升；表格行 hover 靛蓝微染 `rgba(99,102,241,0.07)`；徽章 999px 胶囊带边框色；主按钮渐变+发光
- **布局**：max-width 1200px，4px 基准间距，KPI 4 列/风险卡 3 列
