## 一、核心原则（8 条，不变）

| 原则 | 内容 |
|------|------|
| **P1** | 方向决定全场——胜/平/负严格对应主队进球与客队进球的大小关系 |
| **P2** | 比分必须匹配方向——TOP3 全部指向同一全场结果 |
| **P3** | 半全场第二字必须匹配方向——第二字=胜/平/负与全场方向一致 |
| **P4** | 交叉校验强制执行——方向→比分TOP1→半全场TOP1 三者指向同一结果 |
| **P5** | **完全不参考盘口**——不提及任何亚盘/水位/升盘降盘信号（详见盘口词黑名单）|
| **P6** | 规则必须基于 ≥50 场历史数据，禁止单场补丁式规则 |
| **P7** | 赛后复盘禁止修改预测，偏差→转规则→下一轮生效 |
| **P8** | **比分第一性，总进球参考比分（核心铁律）**——比分 TOP3 必须是泊松 λ 下概率最高的合理比分（独立最优，禁止保守化）；**总进球 X·Y 选项由比分 TOP3 推导**：取比分总球数中概率最高的两个（如比分 2-0/3-0/2-1 → 总进球 2·3）。**严禁反向操作**：不得为了凑"总进球"选项而裁剪/修改比分 |
| **P9** | **泊松保守性修正（核心铁律·用户反复强调）**——**泊松比分是按"正常发挥"计算的最稳定比分（天然偏小分 1-0/2-0/1-1），但实际比赛（尤其小联赛/野鸡/揭幕战/对攻场）极易打出偏差比分（大比分/大球）**。因此：比分 TOP3 必须覆盖偏差比分（≥2-2/3-1/2-3 等大球选项），**禁止把比分"优化"回泊松最保守的小分**（如把 3-1 改 1-0、把 2-2 改 1-0 都是错误方向）。R342 的 λ 上调（8/14 实测 +1.14 球/场、88% 场次实际 ≥3 球）正是这一原则的数据基础——比分选择应体现上调后的进球量，而不是回归上调前的保守值 |

| **R341** | **赛季阶段假赛曲线（新·用户确认）** | **赛季初期/揭幕期 = 假赛风险最低**：五大联赛监管严+球队全力争分，认真打（019 阿拉维斯/024 塞维利亚西甲揭幕战 risk 仅 4）；**赛季中后期 = 假赛风险升高**：争冠/保级/欧战资格形势明朗后才有摆烂/放水空间；**小联赛/野鸡 = 任何阶段风险都高**（014 玛丽港芬超垫底 risk 8）。**假赛评分必须与"不确定性"区分**：阵容剧变（R335）/伤停/状态波动是实力变数（降置信度），不是假赛嫌疑（不改 risk 分） |
| **R342** | **R299 偏差回传校准比分（新·8/14 回测实证）** | ⚠️ **泊松低分本质导致比分保守**：8/14 批次 17 场实际场均 4.00 球 vs 预测期望 2.86（偏差 **+1.14 球/场**），88%（15/17）场次实际 ≥3 球。**校准机制**：每批复盘后按分联赛计算实际-预测偏差，下一批 λ 按 60% 吸收上调（防过拟合），比分由校准后 λ 的泊松自然给出（**禁止手动强制 ≥3 球覆盖**）。8/14 分联赛偏差：沙特+1.93/葡超+2.00/法乙+1.43/荷乙+1.40/芬超+1.30/英冠+1.20/日职+1.20/荷甲+1.00；德乙-0.10/瑞超-0.10/挪超 0.00 |
| **R343** | **市场/赔率信息一律不参考（新·用户强调）** | ⚠️ **市场数据（让球/平半/赔率/水位/让步倾向/热度）多为误导与诱骗信息，严禁作为预测依据**（P5 延伸强化）。**只用可核验基本面**：伤停/停赛/排名/近期战绩/攻防数据/历史交锋/阵容变动/联赛参数。联网核实时跳过"彩经/数据解读"中的市场表述段落，仅提取事实性信息（如"普雷斯顿中卫吉布森停赛"✅ vs "主让平/半"❌）。输出检查：方向/比分/逻辑文字出现盘口词即拦截重写 |
