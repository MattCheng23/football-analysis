## 一、核心原则（8 条，不变）

| 原则 | 内容 |
|------|------|
| **P1** | 方向决定全场——胜/平/负严格对应主队进球与客队进球的大小关系 |
| **P2** | 比分必须匹配方向——TOP3 全部指向同一全场结果 |
| **P3** | 半全场第二字必须匹配方向——第二字=胜/平/负与全场方向一致 |
| **P4** | 交叉校验强制执行——方向→比分TOP1→半全场TOP1 三者指向同一结果 |
| **P5** | **完全不参考盘口**——不提及任何亚盘/水位/升盘降盘信号（详见盘口词黑名单）|
| **P6** | 规则必须基于 ≥50 场历史数据，禁止单场补丁式规则 |
| **P7** | 赛后复盘禁止修改预测，偏差→转规则→下一轮生效 |
| **P8** | **比分第一性，总进球参考比分（核心铁律）**——比分 TOP3 必须是泊松 λ 下概率最高的合理比分（独立最优，禁止保守化）；**总进球 X·Y 选项由比分 TOP3 推导**：取比分总球数中概率最高的两个（如比分 2-0/3-0/2-1 → 总进球 2·3）。**严禁反向操作**：不得为了凑"总进球"选项而裁剪/修改比分 |
| **P9** | **泊松保守性修正（核心铁律·用户反复强调）**——**泊松比分是按"正常发挥"计算的最稳定比分（天然偏小分 1-0/2-0/1-1），但实际比赛（尤其小联赛/野鸡/揭幕战/对攻场）极易打出偏差比分（大比分/大球）**。因此：比分 TOP3 必须覆盖偏差比分（≥2-2/3-1/2-3 等大球选项），**禁止把比分"优化"回泊松最保守的小分**（如把 3-1 改 1-0、把 2-2 改 1-0 都是错误方向）。R342 的 λ 上调（8/14 实测 +1.14 球/场、88% 场次实际 ≥3 球）正是这一原则的数据基础——比分选择应体现上调后的进球量，而不是回归上调前的保守值 |
