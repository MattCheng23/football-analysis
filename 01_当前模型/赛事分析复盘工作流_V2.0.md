# 赛事分析复盘工作流 V2.1（2026-08-16 · 并入联赛 v1.1 应用）

> 适用：每批次（竞彩日）完整闭环。核心铁律：只报真实命中率、赛果必须 FotMob FT 确认、盘口词黑名单、禁删优先归档。
> 模型版本：V10.33（联赛参数 v1.1 生效，见 联赛模型v1.1优化汇总_20260816.md）

## 一、赛前（体彩开门期间：周一至五 22:00 前 / 周六日 23:00 前）

1. **接竞彩清单**：按编号段（001/201 开头=一轮）确认场次；竞彩文件为日期权威
2. **逐场基本面**（FotMob 优先，可核验项）：伤停/停赛/首发名单/排名/近期战绩（含客场）/历史交锋/阵容变动（R335）/客队状态（R329）
3. **参数与规则叠加（v1.1 查表顺序）**：
   - ① 定位联赛 → 查参数：`联赛参数校准 V10.33 段`（挪超 λ3.25/主场0.50-0.75、韩职主场0.55-0.75、瑞超主场0.55-0.75、巴甲/美职联平局45%、葡超平局35%、日职 λ3.8/大小3.5、欧冠资格赛大小2.0）；五大联赛用 `五大联赛模型参数_2026-27.md`（西甲 S-L1/2/3）
   - ② 查队伍规则：`队伍特定规则集 #1-23`（🔴 强制叠加+避雷预警，🟡 参考叠加；队伍规则 > 联赛参数）
   - ③ 估 λ：联赛 λ + 主场系数（新表）+ R334 赛季初 +0.3 + 状态/伤停修正
   - ④ 定方向：泊松概率 → 方向+等级，过 **G1-G5 硬约束**（见下）
   - ⑤ 选比分 TOP3：泊松最优 + P9 大球覆盖 + **G1 ≥4 球项强制** + 联赛比分模板（韩职禁1-0/葡超必含2-2/美职联必含1-1/日职禁0-0·1-0/欧冠资格赛主胜含2-0/挪超强队场含3-0·4-0）+ 队伍规则项 + R347 剧本双覆盖/R348 高进球惯性/R349 剧本周
   - ⑥ 半全场：2 正路 + 1 平局变体（正路占 63%）；总进球 R338 由比分推导
   - 赛季规则：R334/R336 揭幕战谨慎/R341 阶段曲线
   - **G1-G5 质检清单（每场必过）**：G1 比分含 ≥4 球项？（小球联赛除外）｜G2 A 级资格？（三维碾压+无避雷/剧本/冷平；韩/巴/葡/美无单方向 A 级）｜G3 韩/巴/美双选？｜G4 主场系数用新表？｜G5 主胜 ≥45% 是否被反转成平/负？
4. **预测输出**（每场）：
   - 方向 + **等级 A+/A/A-/B+/B/C**（B- 并入 C 展示/配色，但结构独立：**B-=2主+1反，C=1主+2反**，配色 绿/蓝/黄/红）
   - 比分 TOP3（P9 大球覆盖 + R347 剧本场双覆盖 + R348 高进球联赛惯性 + **R350 冷门预警-比分联动**：预警方向比分必入 TOP3，B- 反向=预警方向，C 反向=预警方向+相邻方向）
   - 半全场 TOP3（第二字匹配方向 P3）
   - 总进球（仅由比分按 R338 推导，先比分后 ou）
   - 预警：0-0（zeroZero）/ 7+（bigSeven）/ 冷门风险 Top6 / 高价值预警（半全场剧本）
5. **发布**：网页批次更新（含 updated 时间戳）+ 部署
   - ⚠️ 体彩关门后深夜场：基于首发名单的调整版**不上网页**，仅记入 `03_报告复盘/首发调整版预测记录`（本地统计）

## 二、赛中（可选，用户要求时）

1. **节奏**：15 分钟一轮汇报（半场后按此标准）；进球/红牌/半场哨为插报节点；**多场并行时不逐场跟进**（用户拍板）
2. **每轮必查**（FotMob matchDetails）：
   - 比分 + 比赛时间（liveTime）
   - **红黄牌（numberOfRedCards + Card 事件！）** ← 曾漏报红牌，必须查
   - xG / 射门 / 射正 / 控球 / 禁区内触球 / 大机会 / 角球
3. **解读**：对照赛前预测验证剧本（低分拉锯/对攻/围攻打不开等），动态修正比分概率排序
4. **红牌即时修正（S-L2）**：红牌发生在 ≥30 分钟时 → 占优方（红牌前射门/xG 领先）方向升一级 + 总进球上调 +0.5（10 人方 80-90' 崩盘窗口）——019 实证
5. 后台监视器辅助：每 10 分钟存数据 + 状态变化事件日志（`_match_events.txt`）

## 三、赛后（FotMob 显示 Full time 后）

1. **双源核验**：FotMob matchDetails（数字 matchId）FT 确认 + 竞彩文件/其他源交叉；**严禁赛前/实时数据当赛果**
2. **录入 data.js**：
   - results：score（含半场）/ d（方向）/ s（比分 TOP3）/ h（半全场 TOP3）/ signal / sc
   - evidence（FotMob 完整口径）：xG/射门/射正/角球/控球/禁区内触球/大机会/**最佳球员评分**/进球时间线/换人
3. **演戏排查**（自动，每场必跑）：R326 碾压收窄 / R327 占优惨败 / R324 转化率倒挂 / R328 领先收缩 / 补时剧本 / R322 闪击收工 → 结论写入 evidence txt
4. **控分排查**（仅本地，网页 cleanTxt 截断"控分排查："）：时段分布 / 总进球卡位 / 领先方节奏 / 关键事件时机 + **跨线球**判定（2.5/3.5/4.5/5.5）
5. **预警命中判定**：0-0 / 7+ / 冷门风险 / 高价值预警各自命中数（计入近 7 日 KPI）
6. **避雷联动**：新证据 → 更新名单（V0.x）；**验证仅限名单定稿后场次**（前瞻口径，事前预测才算）
7. **首发调整版判定**：填入本地统计记录（与网页版分开统计）

## 四、批次收尾

1. 批次 stats（方向/比分/半全场）+ GLOBAL_STATS 重算更新
2. **联赛级复盘**（R345）：同联赛样本滚动校准（进球率/平局率/大小球/主场系数）
3. **整体复盘**（全部完赛后）：ABC 分级×联赛分层×假赛三维度 → 新规则/参数迭代（V10.xx）
4. 命中率口径：全量 213 场（58.2%）+ 近 7 日 + 8 月 V10（66.2%）+ 总进球/预警命中——网页 KPI 常驻展示

## 已知坑（勿再犯）

- **删除/覆盖备份铁律（用户拍板 2026-08-16）**：删除或覆盖任何文件/内容前必须提前备份（拷到 `D:\Cola\_backup\` 带日期命名，或用归档替代删除）；编辑大文件前先拷贝一份原文件再动手——曾发生 CSS 规则体误删/会话文件损坏等事故
- 搜索摘要不可靠（多次混入旧赛果）——赛果只认 FotMob FT
- FotMob 短链 id 需转数字 matchId（页面 HTML 提取）；read_page 页面有缓存（实时数据用 API）
- 提取脚本过滤 Discipline 组导致红牌漏报——红牌必查 numberOfRedCards
- 统计验证区分"事前预测 vs 事后解释"（避雷名单是事后建立，不可当验证）
- 子代理会话目录禁删；HTTP 禁 Invoke-*；PS 脚本 UTF-8 BOM
