## 评级梯度方法论（2026-08-17 用户拍板：评级=给比赛定方向，禁止无脑套公式，必须逐场 15 维审核）

| 等级 | 判定标准 | 结构 |
|---|---|---|
| A+ | 五大联赛 + 三维碾压 + 零风险因素（无避雷/剧本/冷平/首轮/德比/假球区）| 3 正路 |
| A | 三维碾压（排名差≥8位 + H2H 连续不败 + 攻防总量碾压）+ 无避雷/剧本/冷平（G2）| 3 正路 |
| A- | 达 A 但含一项降级因素（R354 假球区/杯赛/首轮/弱队保级搏命/伤停）| 3 正路 |
| B+ | 优势明确但非碾压（排名差 5-7 位 + 状态/主客/攻防部分支持）| 2正1反 |
| B | 正常优势（实力类略胜，无强矛盾信号）| 2正1反 |
| B- | 接近场 / 信号矛盾（克星 vs 状态、鬼场、保级对话、双弱）| 1正2反 |
| C | 高风险野鸡场（多重不确定 + 假球信号）| 1正2反（方向反向倾斜）|

**审核要点**（逐场必答）：
1. 实力差是否达到"三维碾压"（排名差≥8 + H2H 连续不败 + 攻防总量碾压）→ 达 A 级候选，再查降级因素
2. 降级因素逐项核对：避雷名单 / 剧本标签 / 冷平 / R354 假球区 / 首轮揭幕 / 德比 / 保级搏命 / 伤停——每项降一级（A→A-→B+），但不允许连降两级（如 A 直接到 B- 即套公式错误）
3. 信号矛盾（克星 vs 状态、主客 vs H2H）→ 直接判 B- 或更低
4. 评级区间应随批次自然分布：碾压场给 A 系，不因"小联赛"或"瑞超"标签一律压到 B-（8/16 批 18 场无 A 系=评级失真，002 教训）

## 第二重：R350 冷门预警-主预测强制联动（每场必查，2026-08-18 升级为 100% 执行）

> **V10.38 实证**：rank≤3 触发场次未联动 6 场全错（0/6）且预警方向全对（004 波鸿客胜/009 米亚尔比主胜/014 玛丽港主胜/003 富川主胜/007 AIK 客胜/019 莫尔德主胜）；联动执行 2/4=50%。rank≤3 预警方向命中 8/10=80% vs 预测方向 2/10=20%——**触发场次不联动=必然全错，必须 100% 执行**。

| 步骤 | 内容 |
|---|---|
| 1 | 排好本批 coldRisk 全量排序（覆盖全部比赛，方向=预测反向） |
| 2 | 判断批次规模：≥10 场取前 3；<10 场取第 1 |
| 3 | 命中触发 → 该场**分析整体反向**：方向=冷门方向、比分 TOP3=该方向比分（含 P9 大球覆盖）、半全场第二字匹配 |
| 4 | 方向处标注 **"（冷门第 N，此分析反向）"**（网页可见） |
| 5 | 反向比分必入 TOP3（B- 反向=预警方向+相邻方向） |
| 6 | 发布前逐一核对：触发场次方向是否与 coldRisk 方向一致？（不一致=联动漏执行，必须返工） |

## 第二重·A：逐场抓鬼检查（2026-08-17 用户拍板，每场必做）

> 核心逻辑：**每场分析时逐场抓鬼，看双方是否都正常**——把演戏/控分排查从赛后前置到赛前（005 本菲卡实证：首轮 xG 3.44 碾压弱队 2-2=演戏方铁证，直接推翻"强队客场正路"默认假设）。
> 抓鬼对象 = **双方各自**（强队可能演戏放水/控分；弱队可能配合或爆冷演戏）。

| 检查项 | 内容（命中即标鬼） |
|---|---|
| G1-鬼 | 强队打弱队近期平局/输球（含 H2H 连续不胜/连平）→ 演戏方证据 |
| G2-鬼 | 数据-结果割裂：xG/射门/射正碾压却平/负、转化率倒挂（R324）→ 效率异常 |
| G3-鬼 | 领先收缩/补时剧本/收官剧本历史（R326/R328/补时跨线球）→ 控分模式 |
| G4-鬼 | 强队对特定对手连续配合（H2H 连平/精确卡位比分）→ 对赌默契 |
| G5-鬼 | 避雷名单 🔴/🟡 + 队伍控分标签（R259 控分模式）→ 降置信 |
| G6-鬼 | 近 5 场反常爆发/哑火（R331 单场大胜陷阱/状态突变）→ 剧本信号 |

**结论输出**（每场必写）：「抓鬼：✅ 双方正常 / 🟡 XX 有鬼（证据）/ 🔴 鬼场（强队演戏方）」
- 正常场：按常规 15 维+泊松流程
- 有鬼场：方向/比分按鬼场逻辑调整（平局/冷门覆盖+R350 联动）
- 鬼场证据写入 evidence 供赛后验证（"事前抓鬼 vs 事后实锤"对照）

## 量化速查表（A2：候选规则实战输入）

### TCI 真实战力（λ 计算）
```
TCI = (近10场xG差值 × 0.4) + (对手强度系数 × 0.3) + (主客场调整 × 0.3)
主+0.1 / 客-0.1；λ = 联赛均值 × 攻防比 × 主场系数（近5场状态60% + 赛季均值40%）
```

### 核心缺阵修正（R113/R325/R086）
- 锋线/中场核心缺阵 → 该队进球 -0.4，赢球 -10%
- 头号射手+中场核心双缺 → 客队被零封 +25%
- 客队 ≥4 主力伤缺 → 被零封 +20%、主队大胜 +15%

### R189 比赛重要性指数（1-10，≤4 触发控分/强队收着踢）
争冠/保级=10｜欧战/德比=9｜淘汰赛=8｜中游有目标=6｜无目标=3｜杯赛首回合大领先=2｜友谊赛=1

### 战术克制表
控球vs防反→客不败+15%｜高位逼抢vs出球强→客+0.3｜传中vs防空→主-0.3｜低位vs远射→客+0.2｜快速反击vs高位→客+0.4

### 带球进场标签（R258/R259，全表见队伍规则集 V1.4）
- R258 闪电：该队开场15'进球+20%、半场平局-15%
- R259 慢热：该队开场15'被进球+15%、半场领先-20%
