## 第二重·A：逐场抓鬼检查（2026-08-17 用户拍板，每场必做）

> 核心逻辑：**每场分析时逐场抓鬼，看双方是否都正常**——把演戏/控分排查从赛后前置到赛前（005 本菲卡实证：首轮 xG 3.44 碾压弱队 2-2=演戏方铁证，直接推翻"强队客场正路"默认假设）。
> 抓鬼对象 = **双方各自**（强队可能演戏放水/控分；弱队可能配合或爆冷演戏）。

| 检查项 | 内容（命中即标鬼） |
|---|---|
| G1-鬼 | 强队打弱队近期平局/输球（含 H2H 连续不胜/连平）→ 演戏方证据 |
| G2-鬼 | 数据-结果割裂：xG/射门/射正碾压却平/负、转化率倒挂（R324）→ 效率异常 |
| G3-鬼 | 领先收缩/补时剧本/收官剧本历史（R326/R328/补时跨线球）→ 控分模式 |
| G4-鬼 | 强队对特定对手连续配合（H2H 连平/精确卡位比分）→ 对赌默契 |
| G5-鬼 | 避雷名单 🔴/🟡 + 队伍控分标签（R259 控分模式）→ 降置信 |
| G6-鬼 | 近 5 场反常爆发/哑火（R331 单场大胜陷阱/状态突变）→ 剧本信号 |

**结论输出**（每场必写）：「抓鬼：✅ 双方正常 / 🟡 XX 有鬼（证据）/ 🔴 鬼场（强队演戏方）」
- 正常场：按常规 15 维+泊松流程
- 有鬼场：方向/比分按鬼场逻辑调整（平局/冷门覆盖+R350 联动）
- 鬼场证据写入 evidence 供赛后验证（"事前抓鬼 vs 事后实锤"对照）

## 量化速查表（A2：候选规则实战输入）

### TCI 真实战力（λ 计算）
```
TCI = (近10场xG差值 × 0.4) + (对手强度系数 × 0.3) + (主客场调整 × 0.3)
主+0.1 / 客-0.1；λ = 联赛均值 × 攻防比 × 主场系数（近5场状态60% + 赛季均值40%）
```

### R300 动态平局概率（叠加在联赛平局基线上）

| 排名差≤3 | +8% |
| 排名差≥7 | -5% |

### 核心缺阵修正（R113/R325/R086）
- 锋线/中场核心缺阵 → 该队进球 -0.4，赢球 -10%
- 头号射手+中场核心双缺 → 客队被零封 +25%
- 客队 ≥4 主力伤缺 → 被零封 +20%、主队大胜 +15%

### R189 比赛重要性指数（1-10，≤4 触发控分/强队收着踢）
争冠/保级=10｜欧战/德比=9｜淘汰赛=8｜中游有目标=6｜无目标=3｜杯赛首回合大领先=2｜友谊赛=1

### 战术克制表
控球vs防反→客不败+15%｜高位逼抢vs出球强→客+0.3｜传中vs防空→主-0.3｜低位vs远射→客+0.2｜快速反击vs高位→客+0.4

### 带球进场标签（R258/R259，全表见队伍规则集 V1.4）
- R258 闪电：该队开场15'进球+20%、半场平局-15%
- R259 慢热：该队开场15'被进球+15%、半场领先-20%
