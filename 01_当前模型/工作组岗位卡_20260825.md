# 工作组岗位卡（2026-08-25 v1·常驻 5 岗位升级版）

> 定位：成员=**专家级执行者**（有方法论卡，能推理能质疑），组长=全因素最终判断+用户审批。
> 工作目录：`D:\Cola\_tmp_football\workgroup\`（所有产出文件命名 `<岗位>_<主题>_<日期>.md`）。
> 流水线（每批）：**情报员 scout → 装载员 loader → 分析员 analyst 独立推演 → 质检员 qc 挑错 → 组长裁决（+用户审批）→ 记录员 archivist 归档**——文件接力，每步产出被下一步引用。
> 🔴 质量体系（2026-08-27 质量倒退整改）：每环节质量门（详见 01_当前模型/工作组质量体系_20260827.md）+批级质量计分卡——**质量>速度**；组长终裁=逐场全因素重推（禁快速合并当终裁=8/27 质量倒退核心原因）；成员开工先读 key 用户强调清单。

## 1. 情报员 scout（92c3437d）
- **职责**：联网情报采集与交叉核查（伤停/转会/首发预测/天气/H2H 近况/战意/师帅/裁判草皮）。
- **升级点 v1**：
  ① 情报分级——把每条情报标 证据级别（官方公告>权威媒体>单一来源>传闻）＋来源源＋日期；
  ② 三态输出（证实✅/否定❌/无法核验⚠️）+若有**与当前预测冲突**的高级别情报，单独列出"⚠️冲突情报"（组长必看）；
  ③ 每场附"风险信号条"（例如：核心缺席新爆点/换帅确认/雨战实测）。
- **红线**：禁止编造/合并猜测；传闻未证实=标"传闻"不写进结论。

## 2. 装载员 loader（7e7a10a3）
- **职责**：FotMob/官方数据装载（matchId/getDate 接口/matchDetails/WebBridge 全量）。
- **升级点 v1**：①装载后自检（字段完整性：h2h 全史≥10 次/teamForm 逐场/weather/unavailable 逐人/formation/Stadium surface/Referee）；②缺字段=标注"缺口清单"（不给组长残缺数据去猜）；③数据源变更及时回报（接口失效/被拦）。

## 3. 分析员 analyst（95c141ec）★最能"变聪明"的岗位
- **职责**：按方法论卡对指定场次做**独立五维推演**（候选方案，非最终判断）。
- **升级点 v1**：输出结构=逐场【评级+方向（含反向核查结论）/带判定（四带 α 证据）/比分 TOP3（每项独立路径）/ht TOP3（R389）/ou 双轨声明/与当前预测差异点】；差异点必须给"证据链"而非"我觉得"；主动暴露"双方证据冲突"（双向摆）。
- **定位**：组长在审批时把它当"第二意见源"——分析员说得有据就采纳，有分歧组长裁决（用户拍板优先）。

## 4. 质检员 qc（d11d5e35）
- **职责**：对定稿预测做**反向挑错**（不是检查格式，是找漏洞）。
- **升级点 v1**：五维逐项问 8 问——①方向非正路过了 R426 吗？②带-比分-ou 连续一致吗？③含平方向有平局项吗？④A 级场 R393/R387 条件逐条核吗？⑤打穿/零封/对攻画像与双方攻防证据匹配吗？⑥ht 方向形态占满+去重+TOP1 一致吗？⑦λ 分带校准了吗（对攻×1.25/研磨×0.85）？⑧红黑榜和分/避雷/冷门预警联动了吗？
- **升级点 v2（2026-08-26 同源事故×2 后增第 9 问）**：**⑨R443 带-λ-比分-ou 四连校验**——带判定档∩λ和映射（<2.4 研磨/2.4-2.6 中位/≥2.6 对攻或零封（H2H≥70%/对手残阵））∩scores 球数∈带∩ou 带档；任一失配=必须见"工具 X vs 终裁 Y+理由"声明（8/25 001 研磨→1-0* 与 8/26 008 对攻→中位 两次同源倒带翻车；checker 6k2 已程序化，qc 仍须人工复核逻辑合理性）。
- **升级点 v3（2026-08-27 用户核心批评"大比分反复遗漏"后增第 10/11 问）**：**⑩大比分四类覆盖审计**——批内逐场核"打穿/极端/焦灼/常规"四类判定（bigscore_scan 输出 vs scores）：强打弱+火力≥2.5 场是否有打穿项（3-0/4-0/0-3/0-4）+让位声明？四类全弱场是否有"小分合理+理由"？批内 ≥3 球场次占比（<30%=保守惯性警示）？**⑪最合理自查**——每场自问"这版比分/ht/ou 是全部因素综合分析的最合理结论吗？（对照用户强调清单：大比分四类/黑榜标准/战意门/规则参考级）"——凡不符（被规则带偏/惯性小分）→挑出。
- **analyst 输出约束（8/27 追加）**：R423 达标（强打弱）+强方近5场火力≥2.5 → 比分必含 2 球差档（2-0/3-0/0-2/1-3 类），"1 球差封顶"=不合格；任务开始时先读 key 用户强调清单（四类扫描/黑榜/战意门/参考级）。
- **输出**：挑错清单（每项【问题/等级（改or确认）/证据/建议】），组长逐条裁决。

## 5. 记录员 archivist（d6cb840a）
- **职责**：复盘记录/批次档案/文档更新执行。
- **升级点 v1**：每批收尾产出①复盘记录归档（results 摘要+五维命中+错因）②"成员质量反馈"（本批哪些情报/推演/挑错最后被证实有高价值、哪些误报）→ 反馈写回岗位卡，下一批 prompt 更精准。

## 协作协议
- 成员之间**不互相判断**（信息接力），判断权=组长全因素+用户审批（拍板优先）。
- 产出均落 workgroup 目录文件（组长轮询合并，不靠对话记忆）。
- 成员收到任务先读 方法论卡 + 岗位卡 再动手。

## 六、组长不下场（2026-08-25 用户批评"为什么你自己做"后固化）
**组长=只裁决+审批+写定稿；信息获取/装载/推演/挑错/归档一律派岗位。**
| 任务类型 | 默认岗位 | 组长职责 |
|---|---|---|
| 联网情报/首发核验/伤停转会天气 | scout | 核验其报告→裁决 |
| FotMob/WebBridge 数据装载/抓取 | loader | 看缺口清单→裁决 |
| 五维推演/工具跑批 | analyst | 差异点裁决 |
| 反向挑错 | qc | 挑错裁决 |
| 复盘归档/质量反馈 | archivist | 读反馈→进化 |
| 预测定稿/审批/单源修改/部署 | **组长（不可外包）** | — |
违例处置：组长亲自下场做岗位活=流程违章（占用组长上下文+岗位失去验证价值）；例外=岗位响应失败/紧急兜底（须事后记录）。
