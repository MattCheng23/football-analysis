# 核心逻辑「展示与撰写」规范（V11.47-4·2026-09-12 用户拍板方向）

> 触发：用户两次纠正——①「点进去还是密密麻麻」②「篇幅过长，没有把我需要的关键信息给我」。
> 根因（2026-09-12 定位）：前端弹窗把整段 logic 当纯文本塞进 HTML，`\n` 被折叠 → **无论内容怎么写，展开后都是一整坨**。
> 已修：`app.js` 新增 `logicBlocks()`（逐行渲染＋关键行高亮）＋ `style.css` 逐行引导线；`<details>` 默认展开。

## 一、显示层（已实现·对所有批次生效）

| 项 | 规则 |
|---|---|
| 渲染 | `logic` 按 `\n` 切段 → 段内按 `①②③` 与 `**标签**` 断行 → 每行一个 `.lm-line`（左侧引导线） |
| 关键行 | 以「判定／结论／要点／方向／让位」开头的行加 `.is-key`（主色高亮） |
| 默认 | 弹窗内「完整逻辑」**默认展开**（不再需要二次点击） |
| 字体 | 展开区 13.5px / 行高 2；手机端自适应 |

## 三、硬约束

1. **总字数 ≤2000**（目标 900-1500）；每场规则引用（`V11.x / R\d+ / §`）≤8 处。
2. **禁写**：规则原文引述、历史教训故事、自我辩护式论证、重复让位声明（这些移入复盘记录/报告，不占展示位）。
3. **强制字样**（检查器会查，缺一即 FAIL）：`天气`（含 `°C`＋降水概率＋mm）、`战意`、`红黑榜`、`进球属性`或`带判定`、`大比分评估`、`抓鬼结论`、H2H 逐场（≥4 条）、近5 逐场（≥10 条）。
4. 原文审计：被精简掉的长版分析按场次存入 `03_报告复盘\260912_核心逻辑原文本存档.md`。
5. 票面/判定/结论行**不得因精简而改变**；已开赛/已完赛场次只在复盘窗口内改文本。
