## 二、评级层（纯 ABC 三档）

| 等级 | 标准 | 比分结构 |
|---|---|---|
| A | **R393 达实力差距**（排名差≥6 / H2H 碾压·连续不败·克星 / 身价差 5 倍 / 卫冕冠军）且**无重大风险**（避雷🔴/剧本场/核心伤停≥3无替代/门将停赛）；轻微因素不降级；R387 红榜通道 | 3 正路、**自信单选方向**（无平局占位）；**净胜档覆盖 1-3 全档**（⭐V11.1 强化：A 级主胜/客胜比分含净 3 项，如 4-1/3-0 级——020 国米 4-1 教训） |
| B | 中置信统一档：有优势非碾压 / 接近场 / 平局信号触发双选 | 2正1反（反向仅红黑榜导向） |
| C | 低置信高风险野鸡场 | 1正2反 |

**A 级附加约束（V11.1）**：
- 净胜档扩展：A 级主胜 TOP3 应覆盖净 1/2/3（如 1-0/2-0/3-0 或 2-0/3-0/3-1），客胜同理（0-1/0-2/0-3）
- 实力差距大时（身价差≥5 倍/排名差≥8）净胜档可含净 4+（4-0/4-1 级）
- 红牌风险预判：主队防线后卫伤停≥2+对手边路快 → 大败反向项（0-3/1-3 级）进 TOP3（016 毕尔巴鄂 11' 直红教训）——**但需 logic 声明红牌风险因素**

## 四、比分层（方法论 v4 + V11.1 六条强化）

**完整判定链**（不变）：λ基线 → 攻防画像（零封打穿/漏勺/小球均势/对攻双向）→ 剧本修正 → 大小球参考 → A级自信单选。

**V11.1 强化条款（周六批 7 场方向对比分偏实证）**：

| # | 新规则 | 实证 |
|---|---|---|
| R370-a | **双弱 0-0 强制**：λ和<2.4 且双方攻击弱（近2场≤1球/攻击端重建）+高温慢节奏（≥27°C）→ 比分 TOP3 必含 0-0 | 021 巴伦西亚 0-0/025 尼斯 0-0 双实证 |
| R381-a | **客防线残阵零封并列**：主强（排名差≥6）+客队伤停≥5 或后防全新重组/新帅 0-3 连败 → 主胜比分含零封项（3-0/2-0 级）与对攻项**并列**，禁止只给双方进球项 | 010 埃弗顿 2-0（水晶宫新帅0-3）/018 布伦特 3-0（热刺7缺） |
| R392-a | **大球局零封不过满**：大球局（λ≥2.6）即使对手 10 人/残阵，比分必须含双方进球项（3-1/4-1/4-2 级），零封项≤1 | 017 朗斯 5-2（欧塞尔10人仍进2） |
| R406 | **避雷队打穿保护**：🔴避雷队参与场次，比分不设净档上限，含打穿项（0-3/0-4/0-5 级当对手攻击残）——避雷队评分>实力评分 | 006 首尔 0-7 |
| R390-a | **单向净档双项**：主胜/客胜比分同一进攻方向必含净1+净2（如 1-0 与 2-0 并列），防止单净档（010 教训） | 010/018 |
| R374-a | **平局代表让位**：双选场主方向火力强（近3场≥3球/联赛λ强侧）→ 1-1 让位大比分（维持）；新增：主强大胜场景（对手残阵）**1-1 仍不可占 TOP1** | 018 |

**其余硬约束**（不变）：R392（λ≥2.4 含 ≥4 球项）/R390/R374/R348/R380-383/P9（禁回归保守）。

**进球属性声明**：每场 logic 必写「**进球属性：小球局/大球局（依据）**」。
