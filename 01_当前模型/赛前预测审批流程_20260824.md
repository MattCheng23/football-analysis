# 赛前预测·高强度审批流程（2026-08-24 用户拍板，每批必走）

> 定位：赛前检查卡（13 项）填完+批次定稿后，**发布前的强行审批关卡**。
> 来源：今日 8/24 批 8 场"逐场高强度审批审核"实证——用户逐场问、AI 逐场回到全因素层重新推演、用户拍板、改动立即执行。用户原话："今天的重点流程得总结下来，以后赛前预测就这样，相当于和你对话的流程是高强度的多次审批审核分析。"

## 一、流程总览（7 步闭环）

1. **批量分析定稿**：现有流程不变（15 维全因素→**带判定 zoned_predict 必跑→λ 分带 lambda_est --band**→五维→四类预警→**赛前检查卡全项勾（含⑬反向核查/⑭修正受控）**→**执行校准对照（R405 参考级/ou 主档优先）**→gen_*.py 单源）
2. **第一遍·数据真实性核准**：H2H 近 5-10 次具体比分 / 伤停逐人伤停停赛定性（FotMob 可误标 injury 实为停赛——Lopy 先例）/ 近况逐场解对手（teamForm tooltipText）/ 天气双源开赛时点 / 轮次 / 阵型 / 裁判罚牌史 / 草皮
3. **第二遍·反向证伪**：R426 六项逐场；**重点夜间/凌晨场**（"觉得会爆冷就不查了"=最低级错误，021/022/023 三场全反的根源）；每场假设方向反了做证据对抗
4. **第三遍·五维一致性**：poisson_top / ht_top / check_batch_full 提示级逐条重审 + 带-比分-ou 连续性 + 净档覆盖声明
5. **第四遍·审批关卡（核心）**：**逐场高强度审批**——每场回到全因素层重新推演（不依赖检查器结论），输出「✅ 最优不改 / ✏️ 建议改+证据链+让位声明」，用户逐场拍板
6. **修改执行链**：gen_*.py 单源（scores/logic/upd 三处同改）→ 重建 → node --check → check_batch_full（0 问题）→ bump_version（真实时间）→ wrangler deploy → **专属 URL 验证**（curl 确认改动字段）
7. **全部审批完 → 终版总表**：逐行 ✅/✏️ + handoff（首发核验→赛中→复盘链）

## 二、审批裁决原则（今日用户强调+拍板，固化，优先级从高到低）

1. **🔴 全部因素第一，泊松（松柏）仅佐证**（最高优先级）：禁止以"泊松排序（全域 #1/#2）"替换/推翻全因素结论；全因素先定结论，泊松工具只作一致性佐证，冲突时以全因素为准+写明让位理由（008 教训：把"0-1 全域 #1 12.0%"当理由替换全因素定稿的 1-2，被用户两次批评）
2. **🔴 不丢大球（硬约束）**：λ和≥2.4 → TOP3 必含 ≥4 球项；全因素不支持该大球路径时也必须写"让位声明"（006 教训：2-0/2-1/3-0 无 4 球项→改 3-1）
3. **双向证据同等对待**：Kean 个人 10 次 0 球史 ≠ 佛全队 0 球；H2H 0 胜 ≠ 0 球；H2H 大胜史在核心缺阵时折价（全主力时代数据）
4. **带-比分-ou 连续一致（V11.9 口径）**：先判进球带（四带）→ 比分从带内选 → **ou 双轨制：带判定档 ∩ 比分校验档，不一致取带档+声明；执行校准二（8/25）：含 5+ 球项的 4·5 让位主档 3·4**（003/005/006/008 先例，"不为大比分而大比分"）
5. **净档覆盖与声明**：主/客胜多形态必须覆盖净1+净2；全因素让位时写"净2 让位声明"（010 范例：马拉加中轴线 5-6 缺+3-0 大胜史折价→2-0 让位）
6. **评级 R393 执行校验**：达实力差距（排名差≥6/H2H 碾压/身价 5 倍/卫冕冠军）+无重大风险→A 级 3 正路；重大风险（对手侧核心 ≥3 缺/剧本/避雷/门将停）→B（011 范例：巴拉纳 3 缺+客场+雨战→B 而非 A）
7. **修改可回退**：所有修改只动单源（gen_*.py），审批意见有变化可一键重来——不怕改错，怕不审

## 三、审批时逐场重推演清单（对话中每场必答）

| 维度 | 必答内容（全因素驱动，非概率驱动） |
|---|---|
| 方向 | 15 维重新过+反向核查序号（⑧/②/④/⑤/⑥/⑪…）结论+无平局信号则单选/有则双选的理由 |
| 比分 | 每项列出**独立路径依据**（H2H 具体比分先例/伤停定性/阵型/天气/战意…）+净档+带一致性+**≥4 球项在哪**+让位声明 |
| 半全场 | P4 交叉（比分 TOP1=平→ht TOP1=平形态）+方向形态占满（R389 v2）+R425 逆转形态覆盖 |
| 总进球 | 联动口径交代+λ 上下调因子 |
| 评级 | R393 三条件逐项+重大风险有无（对手侧伤停计数） |
| 存疑处 | **必须摆出双向证据**（支持 vs 反对各列）再裁决，禁止单侧论证（今日 006 范例：3-0 零封 vs 3-1 大球，双向摆完取覆盖全者） |
