```markdown
# FORMULA_SPEC.md
# V9.6.1 公式完整规范

## 一、原始λ计算

```
λ_home_raw = (主队场均进球 / 联赛场均进球) × 联赛场均进球 × 主场系数
λ_away_raw = (客队场均进球 / 联赛场均进球) × 联赛场均进球 × 客场系数
```

| 变量 | 含义 | 单位 | 范围 | 默认值 |
| :--- | :--- | :---: | :---: | :---: |
| 主队场均进球 | 主队近10场场均进球 | 球/场 | 0-5 | DATA_MISSING |
| 客队场均进球 | 客队近10场场均进球 | 球/场 | 0-5 | DATA_MISSING |
| 联赛场均进球 | 该联赛历史场均进球 | 球/场 | 固定值 | 见PARAMETERS.json |
| 主场系数 | 联赛主场优势系数 | 无 | 0.5-1.1 | 见PARAMETERS.json |

**加权方式**：
- 近3场权重：1.5
- 近4-6场权重：1.0
- 近7-10场权重：0.7
- 归一化方式：总权重 = 3×1.5 + 3×1.0 + 4×0.7 = 4.5+3.0+2.8 = 10.3，加权进球/10.3

## 二、对手强度修正

```
λ_home_adj1 = λ_home_raw × (1 - 客队防守指数偏差)
λ_away_adj1 = λ_away_raw × (1 - 主队防守指数偏差)
```

其中：
- 客队防守指数偏差 = (客队场均失球 - 联赛场均失球) / 联赛场均失球
- 主队防守指数偏差 = (主队场均失球 - 联赛场均失球) / 联赛场均失球

## 三、伤停修正

```
伤停修正系数 = f(缺阵球员重要性)

核心球员缺阵（进球/助攻占球队≥30%）：
  头号射手/进攻核心 → 该队进球预期 -0.4球，平局+12%，主胜-10%
  组织核心 → 该队进球预期 -0.3球，平局+8%，主胜-8%
  防线核心 → 该队进球预期不变，平局+10%，主胜-5%
  双核心同时缺阵 → 该队进球预期 -0.6球，平局+20%，主胜-15%
```

详细伤停修正表见PARAMETERS.json。

## 四、伤愈复出状态折扣（R022）

| 伤停时长 | 首战状态 | 次战状态 |
| :---: | :---: | :---: |
| ≥3周（非核心） | 60% | 80% |
| ≥3周（核心） | 75% | 85% |
| 2-3周 | 70% | 85% |
| 1-2周 | 80% | 90% |

## 五、平局修正（R007）

```
平局概率 = max(Poisson平局率, 联赛平局基线) × 条件修正系数
条件修正系数 = 1.0 + 排名差修正 + 进球和修正 + 失球和修正

排名差修正：
  排名差≤3 → +0.20
  排名差4-6 → +0.05
  排名差>6 → -0.10

进球和修正：
  双队场均进球和≤1.8 → +0.15
  双队场均进球和≥3.0 → -0.10

失球和修正：
  双队场均失球和≤2.0 → +0.10
  双队场均失球和≥3.0 → -0.05
```

## 六、最终概率归一化

```
修正后1X2概率 = [主胜概率, 平局概率, 客胜概率]
总和 = 主胜 + 平局 + 客胜
归一化后 = 修正后概率 / 总和
```

## 七、比分分布

```
P(i,j) = Pois(λ_home_final, i) × Pois(λ_away_final, j)
```

其中 i, j ∈ [0,5]。

平局比分修正（韩职R013）：
- 当方向=平且联赛=韩职时：
  - 1-1权重 = 50%
  - 0-0权重 = 25%
  - 2-2权重 = 25%

## 八、半全场计算

```
半场λ_home = λ_home_final × 0.45
半场λ_away = λ_away_final × 0.45
半场比分矩阵 = Pois(半场λ_home, i) × Pois(半场λ_away, j)
半全场概率 = 半场比分 × 全场比分（基于剩余进球）
```

## 九、数据缺失处理

| 缺失字段 | 处理方式 |
| :--- | :--- |
| 伤停信息 | 按无伤停处理，标记"无伤停数据" |
| 近期状态 | 使用联赛平均值 |
| 历史交锋 | 权重从标准值降至50% |
| 核心球员数据 | 停用该组件 |
| 多个字段同时缺失 | 整场弃权 |
```

## DATA_BINDING_RULES.md

```markdown
# DATA_BINDING_RULES.md

## 1. 最近多少场比赛
- 使用最近**10场**比赛
- 若球队为新赛季/升降级，使用最近**5场**比赛

## 2. 是否区分主客场
- 是。分别计算主场进球、客场进球、主场失球、客场失球

## 3. 是否只使用同联赛历史
- 是。不跨联赛混合

## 4. 时间衰减
- 是。半衰期：最近3场权重1.5，4-6场权重1.0，7-10场权重0.7

## 5. 是否使用升降级前数据
- 否。只使用当前赛季数据

## 6. 是否使用杯赛、友谊赛或其他联赛数据
- 杯赛：仅使用同赛事杯赛数据
- 友谊赛：不使用
- 其他联赛：不使用

## 7. 如何计算攻防强度
- 场均进球 = 总进球 / 场次
- 场均失球 = 总失球 / 场次
- 攻防指数 = 场均进球 / 联赛场均进球

## 8. 对手水平修正
- 客队防守指数偏差 = (客队场均失球 - 联赛场均失球) / 联赛场均失球

## 9. 如何处理红牌、伤停、轮换
- 红牌停赛：视为伤停
- 伤停：根据缺阵球员重要性进行修正
- 轮换：如果赛前已知轮换信息，调整预期

## 10. 最晚数据使用时间
- 开赛前**1小时**。开赛后数据不得使用

## 11. 预测后的比赛信息是否进入计算
- 否。严格赛前

## 12. 赔率来源
- 数据来源：DATA_MISSING（无固定赔率数据源）

## 13. 数据冲突处理
- 以官方数据源为准

## 14. 球队名称绑定
- 使用标准名称，手动绑定

## 15. 缺失字段处理
- 对阵不一致 → 弃权
- 伤停缺失 → 停用伤停组件
- 赔率缺失 → 停用赔率组件
```
