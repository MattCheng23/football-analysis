# 第一部分：核心原则（死规定，不可违背）

## 原则1：方向决定全场
- 方向"胜" → 全场主队进球 > 客队进球
- 方向"平" → 全场主队进球 = 客队进球
- 方向"负" → 全场主队进球 < 客队进球

## 原则2：比分必须匹配方向
- 方向"胜" → 比分TOP3全部为主胜比分
- 方向"平" → 比分TOP3平局比分占多数
- 方向"负" → 比分TOP3全部为客胜比分

## 原则3：半全场第二字必须匹配方向
- 方向"胜" → 第二字=胜（胜胜/平胜/负胜）
- 方向"平" → 第二字=平（胜平/平平/负平）
- 方向"负" → 第二字=负（胜负/平负/负负）

## 原则4：交叉校验强制执行
每次预测输出前必须执行：方向→比分TOP1→半全场TOP1三者指向同一全场结果，任一不匹配则强制修正后再输出。

## 原则5：完全不参考盘口（V9.3固化）
- 不参考任何亚盘/让球盘/水位/升盘降盘信号
- 不提及盘口术语（如"初盘/即时盘/退盘/升盘/诱上/诱下"）
- 仅使用基本面（球队实力、排名、状态、伤停、交锋、战意）+ 竞彩标准盘赔率

## 原则6：规则必须基于基线数据（V9.5新增）
- 任何规则必须有≥50场历史数据支撑
- 禁止基于单场/单轮赛果创建新规则
- 禁止“赛后补丁式”修正（如因某场0-2就固化0-2权重）

# 第七部分：输出格式标准

## 一、标准输出格式
```
【联赛/赛事】主队 vs 客队 | [首回合/次回合]

方向：胜/平/负（置信度）
比分TOP3：① X-X ② X-X ③ X-X
冷门比分：X-X（概率等级：较高/中等/中等偏低/较低）｜冷门逻辑：[一句话]
半全场TOP3：① XXX ② XXX ③ XXX
大小球：大/小 X球
【高价值预警】
逆转组合：XXX（概率等级：中等/中等偏低）｜逻辑：[一句话]
0-0防范：X%（概率等级）
核心逻辑：[一句话]
```

## 二、置信度等级标准

| 等级 | 判定标准 |
| :---: | :--- |
| **A级** | 方向概率≥65%，方向明确，可作胆材 |
| **B级** | 方向概率55~65%，需防范平局/冷门 |
| **C级** | 方向概率45~55%，仅输出概率分布 |
| **D级** | 方向概率<45%，无明确方向 |

## 三、0-0防范概率等级标准

| 等级 | 概率区间 | 输出方式 |
| :---: | :---: | :--- |
| **较高** | ≥20% | 单独标注“较高” |
| **中等** | 12~20% | 标注“中等” |
| **中等偏低** | 8~12% | 标注“中等偏低” |
| **较低** | <8% | 不输出 |
