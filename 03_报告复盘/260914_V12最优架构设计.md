> 用户口径（2026-09-14）：「**不能只靠模型来做赛前分析，而是需要你去考虑全部因素去判断审核**」
> 本文件＝在此口径下我认为的最优设计。上位依据：`260914_V12升维路线图.md`（含 32 组网格与否决项）。

## 一、先定原则（为什么不能是"模型替代 LLM"）

| 事实（均有实测证据） | 推论 |
|---|---|
| 32 组网格：**方向 0/32、ht 17/32（均值 +0.5pp）** 优于 V11 | 模型**不能**接管判定 |
| V11 全库基线：方向 65.8%／比分 30.0%／ht 60.9%／ou 41.6% | LLM＋规则才是当前的真上限来源 |
| 0913 批方向 90.5% vs 全库 65.8% | **批次方差**是 V11 最大的病，不是水平问题 |
| 物理/信息上限：比分≈40%、ou 2 档≈50-60% | 「五维都暴涨」不存在，突破只能是体系性的 |

⇒ **V12 的正确形态＝LLM 保留全部因素的主判权；模型做 LLM 结构性做不到的四件事。**

## 二、三层架构

### 第 1 层｜结构化底座（数据纪律·已部分落地）
1. **赛前特征 100% 机器可读** —— `【特征】lam=… inj_h=… form5_h=… h2h_w=…`（V11.55-1·0915 起强制·缺键 ERROR）
2. **每批自动入库** —— `v12_ingest.py` 已接批末管线（v12db 607 条）
3. **滚动强度特征（漏洩安全）** —— 该队**既往**场均 xG/xGA、半场进球倾向、首球时间（`v12_ht_features.py` 已建）
4. **历史挖掘** —— 会话日志挖掘（进行中；**必须过 `v12_reconcile_mined.py` 对账才能用**）

### 第 2 层｜模型仪表盘（**四个角色·均不抢判定权**）
| # | 角色 | 做什么 | 为什么只有模型能做 |
|---|---|---|---|
| **①** | **概率校准器** | 输出 P(主/平/客)、P(比分)、P(ht 组合)，与 LLM 判定并列 | V11 **结构上没有概率**；校准（Brier/可靠性）无法由规则给出 |
| **②** | **分歧审计器** | LLM 判定 ∉ 模型 top-k 或 P 过低 → **强制写分歧说明＋进分歧台账** | 人/LLM 自查有盲区；独立第二判断才能暴露过度自信 |
| **③** | **机械决策代理** | λ、泊松表、第 4 档取档、让位成本、形状映射 → **脚本产出**（LLM 只审不改算） | 今晚 018 的形状取档错、多次算术错＝LLM 不该手算 |
| **④** | **退化雷达** | 按维度/联赛/批次滚动监控命中率，超阈值报警并自动跑网格协议 | 批次方差极大＝需要自动监控而非人眼 |

### 第 3 层｜主判（LLM·保留全部因素）
- 15 维全因素＋用户尺＋抓鬼六查＋演戏/控分排查＋条款库；**有最终判定权**
- **义务**：必须**回应**仪表盘的每个分歧/低置信标记（回应＝写理由，**不是必须改判**）
- 输出：票面 ＋ 每项置信度 ＋ 让位声明 ＋ 【特征】行

## 三、审核机制（用户强调的"判断审核"）

```
LLM 主判  ──┐
            ├─→ 双轨审：①LLM 自审（§13 七项＋两档制）  ②仪表盘审（概率/分歧/机械一致性）
仪表盘    ──┘         │
                      ├─ 一致 → 出稿
                      └─ 分歧 → **不自动改判**，写「分歧台账」（谁主张什么、依据、价位）
                                     │
                                     └─→ 批末复盘结算：谁对 → 记入「场景化分工表」
```

**场景化分工表（长期演化的核心）**：按场景（低 λ 研磨场／豪门打穿场／双黑对碰／杯赛后疲惫场…）统计
「LLM 对」vs「模型对」的比分 → **该场景谁强就用谁的主张**。这是 V12 唯一能真正超越 V11 的路径：
**不追求全局超越，追求分场景的最优委派。**

## 四、验收标准（怎么算 V12 成功）

| # | 标准 | 门槛 |
|---|---|---|
| 1 | 特征覆盖率（赛前机器可读） | ≥95% |
| 2 | 校准质量 | 可靠性图/ Brier 优于"常数概率"基线（**不是只看命中率**） |
| 3 | 分歧台账结算 | 某一类场景下采纳模型建议**确实提升命中** ≥3pp |
| 4 | 五维 | 方向≥72%／ht≥72%／比分≥33%／ou≥50%（各自天花板内） |
| 5 | **批次方差** | 批间方向命中率极差收窄（当前 65.8%~90.5%） |

## 五、执行优先级（把不需要打赢 V11 的先做出来）

| 优先级 | 动作 | 为什么先做 |
|---|---|---|
| **P0** | **③ 机械决策代理**（λ/泊松/第4档/让位成本脚本化） | **不需要超过 V11**，只需"算对"；直接消除今晚那类算术/形状错 |
| **P0** | **① 概率校准器** | 给 LLM 判定配置信度 → 立刻可用于选场/仓位 |
| **P1** | **② 分歧审计器＋分歧台账** | 把"判断审核"制度化、可结算 |
| **P2** | 底座补强（挖掘对账／向前积累特征） | 提升 ① 的校准质量 |
| **P3** | **场景化分工**（等台账积累） | V12 超越 V11 的唯一现实路径 |

> **一句话**：V12 ＝ **让 LLM 判得更准（全因素不变）＋ 让机器负责"算对、盯住、质疑"**。
> 突破不来自某个模型，而来自**分工＋审计＋分场景委派**这三件 V11 结构上做不到的事。
