## 一、诊断：七个问题，其中一个是致命的

### ① ★致命：**「反环」是负向指标**（当前唯一的升级依据）

现规则：`反环 ≥2 → 冷门等级升为「中等」`。实测兑现率：

| 反环数 | n | 冷门兑现率 |
|---|---|---|
| 1 项 | 39 | **35.9%** |
| 2 项 | 35 | 22.9% |
| 3 项 | 26 | **11.5%** |
| 4 项 | 17 | 11.8% |

**反环越多，冷门越不容易兑现——与规则假设完全相反。**

**并且排除了「机械伪影」解释**（即"反环多 → 方向做宽 → 冷门侧被挤成残项"）：

| 控制方向集大小 | 反环≤1 | 反环≥2 | 差 |
|---|---|---|---|
| 方向 1 项 | 30.0%（n=10） | **7.7%**（n=13） | −22.3pp |
| 方向 2 项 | 34.5%（n=29） | **19.4%**（n=62） | −15.1pp |

两层内均反向 ⇒ **不是方向集宽度的副作用**。（另核：登记冷门侧的赛前概率 P_cold / 方向集外最高概率 P_best ≈ **0.99**，说明冷门侧并非"残项"，其概率并不低。）

### ② 级别不由自己的规则决定（软判定）
`反环≥2` 却是「低/参考级」＝ **36 场**；`反环≤1` 却是「≥中等」＝ **8 场**。
⇒ 级别不是反环数的函数，是**逐场软判断**，无法复核。

### ③ 五级制实际只有三级，且塔尖空缺
| 级别 | n | 占比 |
|---|---|---|
| 低 | 99 | 48.8% |
| 中等 | 75 | 36.9% |
| 参考级 | 25 | 12.3% |
| 中等偏高 | 3 | 1.5% |
| 中等偏低 | 1 | 0.5% |

**「高」从未使用；「中等偏高」仅 3 场**。而「参考级」在 logic 里本是**句式词**（"→ 参考级低／参考级中等"）却被当成级别值 ⇒ **标签语义污染**。

### ④ 级别判别力弱（方向对，幅度小）
本抽取：≥中等 **30.8%**（n=78）vs 参考级/低 **22.4%**（n=125），差 +8.4pp，**z=1.33 不显著**。
技能记载（更大样本）：≥中等 36.1%（n=335）vs 24.7%（n=259），Fisher p=0.0032。
⇒ 效应真实但**只有 +8~11pp**，与 DIR-1R（你 9/6 的判断）一致：**预警命中率≈自然频率，只能当证据筛**。

### ⑤ 链环数（链 X/5）无判别力
| 链环数 | n | 兑现率 |
|---|---|---|
| 2/5 | 22 | 27.3% |
| 3/5 | 60 | 23.3% |
| 4/5 | 23 | 26.1% |

无单调关系 ⇒ **顺环计数同样不构成信号**。

### ⑥ 概率引用率仅 9.9% ⇒ **校准永远无法评估**
203 条中仅 20 条能解析出赛前冷门概率。你要求的"看赛前给的冷门概率"目前**在数据上做不到**（0917 批是少数例外，11/11 都写了）。

### ⑦ 冷门侧选向 22.6% 违规（前一轮已立 CR-1）
全量可核 53 场违规 12 场，11/12 为同一模式：单选方向时把「反向胜」当冷门侧而漏掉「平」。

## 二、根因归纳：**三件正交的事被压成了一个标签**

| 概念 | 它回答的问题 | 现状 |
|---|---|---|
| **冷门概率** | 哪个结果更可能（且非我方向） | 混在 lvTxt 里，且**无机械定义** |
| **冷门证据** | 有没有独立于概率的额外信号 | ＝反环计数，**已证负向** |
| **抓鬼（诚信）** | 这场结果**可不可信**（放水/演戏/轮换） | 散落在 logic 文本（"抓鬼：🟡…"），**无字段、无结算** |

**「让抓鬼更精准」做不动的根本原因**：抓鬼与冷门概率被混为一谈，
于是既没有独立的抓鬼判据，也没有抓鬼的赛后结算——**无法知道哪次抓鬼是对的**。

## 三、重构方案：四层结构（逐层可机械验证）

### 第 1 层｜冷门概率（机械可算）—— 替代现有软判定级别
新增字段：
```
coldP: 18.4          // 赛前冷门侧概率（%），必须写
coldPct: 62          // 该概率在近 200 场的分位
lvTxt: 机械映射       // P≥P80→高 ｜ P60-80→中等偏高 ｜ P40-60→中等 ｜ P20-40→低 ｜ <P20→极低
```
- **级别不再由"反环几项"决定，而由分位决定** ⇒ 可复核、跨批可比、可写检查器
- **CR-1 同时生效**：`dir` 必须＝方向集外概率最高项（检查器已具备）
- 现有 `低/参考级/中等/中等偏高` 语义废弃，统一为**五分位**（并保留旧值只读兼容）

### 第 2 层｜冷门证据（反环重建）
- **立即停用「反环数」作为升级依据**（已证负向，n=118；停止前须在更大样本复核）
- 改为**逐项登记 + 逐项赛后结算**：
```
anti: [
  { item: "队级克星史(H2H近5不胜)", face: "因果", dirHyp: "+3pp", hit: null },
  { item: "客战平率60%",            face: "概率", dirHyp: "+0pp", hit: null }
]
```
- **强制区分两面**：`因果面`（克星史/放水模式/核心缺阵/主场不败史/轮换动机）vs `概率面`（历史频率复述，与泊松重合，**不计为独立证据**）
  —— 你 8/31 的人工重判已识别此事（"国米客战平率60%＝概率面非因果面"），但从未机械化
- **赛后结算**：每项标 `hit`，累计后即可回答「**哪一类反环项真有预测力**」——这是现在完全缺失的闭环

### 第 3 层｜抓鬼（诚信风险，与冷门概率**正交**）
独立字段，**不参与冷门级别**，只影响**规避与信心**：
```
ghost: {
  lv: 无/留意/高,              // 诚信风险等级
  six: { R321:…, R322:…, R326:…, R327:…, R328:…, 闪击:… },   // 演戏六查逐项
  stake: "双方均有出线动机" | "强方已出线→轮换" | …,
  conf: 0.85                   // 对本场结果为真实竞技的信心
}
```
- **抓鬼的作用不是"押冷门"，而是"决定这场要不要买/要不要让位"**
- 与冷门概率正交：可以「冷门概率高 + 诚信无虞」（正常冷门），也可「冷门概率低 + 诚信存疑」（该回避）
- **赛后结算 `conf`**：结果与数据割裂的场次 → 校验抓鬼是否提前识别（现有 R326/R327 已有一套，但无字段）

### 第 4 层｜冷门剧本（把已写好但不可统计的内容结构化）
现在 logic 里其实**剧本写得很好**（001「中国打平即锁第1 → 轮换/控场收工」），但没有字段 ⇒ 无法统计哪类剧本靠谱。
```
script: "打平即出线→轮换" | "双线疲劳" | "新帅磨合" | "核心停赛" | "无"
scriptHit: null    // 赛后判定剧本是否兑现
```
⇒ 累计后可回答「**哪类冷门剧本的兑现率最高**」——这才是"丰富内容"的正解，而不是再加形容词。

## 四、覆盖率治理（回应你「大范围覆盖」的批评）

| 措施 | 内容 |
|---|---|
| **批级配额** | `lvTxt ≥ 中等` 的场次 **≤30%**（当前 38.9%）；超出须写"为何本批冷门面确实宽" |

| **概率引用义务（CR-3）** | `coldP` 必填（当前引用率 9.9%），否则校准永远无法评估 |
