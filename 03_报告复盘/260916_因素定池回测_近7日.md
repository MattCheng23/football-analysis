## 2. 判池规则与最优阈值

### 2.1 从 formH/formA 解析出的因素（每队）
form 原文形如 `09-11 主 Bangkok United 1-0 胜`，逐条解析出：`主客`、`本队进球`、`本队失球`、`胜平负`。再算每队：

- **场均进球** `gf`、**场均失球** `ga`、**场均净胜** `net`
- **合计场均总球** `pair_total = (主队场均总球 + 客队场均总球) / 2`

> ⚠ **口径坑（已修正，如实记录）**：`主队场均总球 + 客队场均总球` 的量纲是 **2×每场总球**（本例均值 ≈5.8 而非 ≈2.9）。第一版直接拿它跟 2.2~3.0 的阈值比，导致**池B 永不触发、14 场全判进池C**，网格搜索整片失真。修正为两队取平均后池B 才正常触发。**报告里所有数字均为修正后口径。**

### 2.2 判池器（阈值全部由网格搜索得出，非手填）

```
sH        = 主队场均进球 − 客队场均进球
strong    = (sH >= 0) ? 主队 : 客队      # 强方
weak      = 弱的一侧                     # 弱方
total     = (主队场均总球 + 客队场均总球) / 2
ratio     = max(λh,λa) / min(λh,λa)

1) |sH| >= adv  且  weak.ga >= weak_ga  且  (不设λ比门 或 ratio >= ratio门)  →  池A（方向取强方）
2) 否则  total <= tot                                                        →  池B
3) 否则                                                                      →  池C
```

### 2.3 网格搜索：3(adv) × 4(weak_ga) × 6(tot) × 4(ratio) = **288 组**（分母固定 N=14）

搜索范围：`adv ∈ {1.0, 1.5, 2.0}`、`weak_ga ∈ {1.4, 1.6, 1.8, 2.0}`、`tot ∈ {2.6, 2.8, 3.0, 3.2, 3.4, 3.6}`、`λ比门 ∈ {不设, 1.6, 1.8, 2.0}`。
（`tot` 的下限由 2.2 抬到 2.6 —— 因为量纲修正后 2.2/2.4 已低于样本正常区间。）

**★ 最优配置（按 NEW 命中数，并列取 HYBRID 高者）：`adv=2.0 / weak_ga=1.4 / tot=3.0 / λ比门=不设`**
池分布：**A=1 场、B=5 场、C=8 场**

**★ λ比门消融**：**最优解落在「不设 λ 比门」上** —— 即**纯因素定池**最好。任何 λ 比门（1.6/1.8/2.0）都只会让结果**不变或更差**。题设建议的 `λ比 ≥2.0` 恰恰是最优解要丢掉的那一条。

### 3.3 ★ 根因：近 5 因素在三个形状池上没有判别力

按「实际比分归属」分组，看四个候选因素的均值：

| 实际归属池 | N | \|进攻差\| | 弱方场均失球 | **合计场均总球** | λ比 |
|---|---|---|---|---|---|
| **A 单方碾压** | 2 | 1.10 | 1.43 | **4.22** | 2.21 |
| **B 小分焦灼** | 5 | 1.44 | 1.28 | **3.32** | 1.45 |
| **C 对攻大球** | 7 | 0.73 | 1.40 | **2.90** | 1.75 |

**这张表直接解释了为什么新法不行**：
1. **「合计场均总球」的方向是反的** —— 按定义池B（小分）应最低、池C（对攻）应最高；实测 **A=4.22 > B=3.32 > C=2.90**。**最碾压的一型反而合计总球最高，最对攻的一型反而最低。**
2. **「弱方场均失球」三型几乎贴在一起**（1.43 / 1.28 / 1.40），**没有区分度** —— 而它正是池A 的准入条件之一。
3. **「\|进攻差\|」排序也不支持定义**（B 1.44 > A 1.10 > C 0.73）。
4. 唯一同向的是 **λ比**（A 2.21 > C 1.75 > B 1.45），但**这恰恰是已做过否证的旧路径** —— 用 λ 定池上一版已被证明更差（319 场：池优先 26.6% vs 现有 28.2%），本回测的最优解也把 λ比门整个删掉了。**能用对了的那个因素偏偏是没用的那条路。**

**结论：所谓「用因素定池」，实际是拿一组对形状无判别力的指标在做分类 —— 分类错了，池内取前三就变成了「在一个错的集合里做对的泊松」，当然打不过全局泊松前三。**

### 3.4 机制层：为什么「池内取前三」会输给「全局取前三」
池约束是**硬过滤**：一旦判错池，全局最可能的档位就被**完全排除在票面外**。14 场里现成的三个例子：
- **002 大田市民 1-0**：判池C → 票面 `3-1 / 2-2 / 3-2`，而实际 1-0 属池B，被整池排除。
- **006 阿布扎比艾因 4-0**：判池C 且方向判客 → 票面 `2-2 / 1-3 / 2-3`，实际 4-0 属**池A 主向**，双重错。
- **007 巴列卡诺 2-1**：判池C → 票面 `2-2 / 3-1 / 1-3`，实际 2-1（跨池白名单 B∪C）被挤出前三，而 OLD 命中了。

> **对比**：现行 OLD 是「全局泊松前三 + 条款打补丁」，**在概率层排序、只在边际上用规则修正**，不会因为一个分类错误就整池作废。**在分类器准确率只有 35.7% 的前提下，硬池约束的期望损失大于收益。**

## 5. 结论：能不能反超 OLD？

### 5.1 直接回答
| 问题 | 回答 |
|---|---|
| 用因素定池能超过 OLD 吗？ | **不能。** |
| 超出多少 pp？ | **+0.0 pp**（NEW 3/14 = 21.4% = OLD 3/14 = 21.4%） |
| 样本量？ | **N = 14**（分母 14；三法分母完全一致） |
| 288 组阈值里有更好的吗？ | **没有，最高就是 3/14。** 最差可到 1/14（−14.3 pp）。 |
| 唯一同 λ 的 6 场子集？ | **OLD 2/6=33.3% ｜ NEW 0/6=0.0% ｜ HYBRID 1/6=16.7% —— 新法差 33.3 pp** |
| 如果只看 HYBRID？ | 也是 **3/14 = +0.0 pp**，同样没反超。 |

**不美化：因素定池在本样本上没有提升，连打平都建立在「恰好同数」上；一换到真正同 λ 的可比子集就明显更差。**

### 5.2 为什么（两条硬证据）
1. **近 5 因素对三个形状池没有判别力**（§3.3）：合计场均总球的排序**与池定义相反**（A 4.22 > B 3.32 > C 2.90），弱方场均失球三型贴平（1.43/1.28/1.40）。判池准确率仅 **5/14 = 35.7%**。
2. **λ比是唯一同向的因素，但它正是已被否证的旧路径**：上一版用 λ 定池在 319 场上已经输了（池优先 26.6% vs 现有 28.2%）。本回测最优解也把 λ比门整个删掉了 —— **两条路都堵死**。

### 5.3 该不该上这个方案？
## ❌ **不该上。**

理由（按权重排序）：
1. **没有证据支持**：288 组阈值全部 ≤ OLD，天花板就是持平。
2. **可比子集上明显更差**：6 场三法同 λ → NEW 0/6 vs OLD 2/6。
3. **机制代价是实打实的**：池约束是硬过滤，判错池就整池作废（§3.4 三个现成例子）。当前判池准确率 35.7% 的前提下，**期望损失 > 收益**，且 31 档面板本身还有 14.3% 落在三池之外。
4. **前提条件（formH/formA 结构化字段）只在 1/7 的批里存在** —— 即使效果持平，为了一个零增益的改动去回填全部历史批的结构化字段，**投入产出比为负**。
5. 题目问的「用因素定池能不能反超」已答完：**不能**。这也把上一版否证（机械 λ 定池更差）补上了另一半 —— **换成因素定池一样更差/持平，「先定池再取前三」这条路在两个实现上都否证完毕。**

### 5.4 如果仍要验证，需要什么（不是建议现在做）
- **样本是唯一瓶颈**：需要把 `formH/formA` 结构化字段回填到 2026-09-09~09-13 的批，把 N 从 14 提到 **80–100 场以上**才能对 +10pp 有功效（当前 11%）。
- **不要用 n=14 再调阈值**：本次最差 1/14、最好 3/14 全在同一批上，**任何阈值差异都在噪声内**（留一法 78.6% 的「稳定」是并列最优的假稳定，§2.5 已说明）。
- 若将来重测，**建议直接测「软池」而非硬池**：把池当**概率加权/排序先验**而不是**硬过滤**，避免单次分类错误整池作废。
