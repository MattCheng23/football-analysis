## 三、本轮踩到的坑（已修正·写进流程）

1. **token 静默未插入**：CSS 里 token 是**顶格写**（行首无空格），我的插入锚点带了两个空格 → 替换 0 命中**却报告成功**，导致 19 个规则块引用 `var(--primary-solid)` 而它未定义（背景失效）。→ 复验发现并修；脚本已改为「每次替换断言 count==1，否则报错退出」。
2. **探针量测误差**：`getComputedStyle` 读到的背景是**未合成的 rgba**（卡片 92% 透明），直接算对比度会低估（3.83 vs 实际 5.35）→ 结论以「合成底色」为准。
3. **evaluate 语法错**：JS 里 `push({...);` 少一个大括号 → 扩展报 `Unexpected token ')'`；已加 node --check 前置校验（`check_ev_js.py`）。
