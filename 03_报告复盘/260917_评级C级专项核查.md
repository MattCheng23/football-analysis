## 四、根因（两个叠加，非"评级变严"）

### 原因 A：本批卡司系统性落在评级链的「证据盲区」
1. **③ H2H 通道 8/11 不可用**——欧罗巴联赛阶段**首轮** 5 场、亚冠乙**首轮**、西甲跨级对阵全部「无交锋记录」（010 唯一先例 2018 年＝JK-2 失效级）。**首轮/新赛制对阵是 H2H 的结构性盲区**，这是本批最大单一原因。
2. **① R423 身价通道跨联赛取不到数**——009/011「身价未获取」，010「身价 9.8 倍达标但同联赛排名差 0 位、H2H 失效级」（规则要求叠加状态/H2H 佐证）。**跨联赛对阵（欧战/亚冠/解放者杯）是 R423 的结构性盲区**。
3. **② 状态链要求"强方好＋弱方崩"两侧同向**，本批多场**反向**：003 弱方 OFI 主场 4 战全胜而强方霍芬海姆德甲 3 轮仅 1 胜（方向相反）；005 两侧皆不满足；010 强方比利亚雷亚尔近 5 **0 胜**。

### 原因 B：C 级语义已换代，且实操存在「向上兜底」
- **语义换代**：R337 旧文定义 **C＝低置信高风险野鸡场（方向反向倾斜、比分含反向覆盖）**——历史上 3 场 C 全部符合该形态（芬超/日职联/韩职 弱联赛 + dir 为「负」「平/胜」「负」）。**本批 5 场 C 全部是强方场、方向无一反向倾斜**，属 9/6 晚拍板的 **A 级判定法 v2「≤1 正路＝C（低置信）」语义下的首次批量触发**。
- **⚠ 向上兜底（本批发现）**：**008 与 011 按规则字面（1 正路）应判 C，实判 B**；若严格照规则，本批应为 **C 7 场 / B 2 场**，实际 **C 5 / B 4**。这正是「C 级长期不出现」的可解释机制之一——**1 正路场被人工向上兜到 B**。现有检查器 R393 只校验「dir 评级 ↔ logic 评级」一致性（字符串层），**不校验「正路数 → 档位」的算术对应**，故此类偏差无机器拦截。
