## 二、完整版本演进时间线

### 阶段 1：世界杯模型时代（07-11，会话A）
- **v3.1.3（起点）**：世界杯淘汰赛专用，**九大因子加权模型**：进攻火力20% / 防守稳固15% / 伤停15% / 核心球员爆发15% / 弱旅反击10% / 替补爆发10% / 历史交锋8% / 体能场地5% / 门将伤病5%，各因子 0-10 分量化评分

### 阶段 2：韩职适配（07-11 ~ 07-15，会话A）
- **v3.2.x**：世界杯模型移植韩 K 联，接入 xG 数据，回测方向 89.7%、比分 83.8%
- **v4.0**：赛前/赛中动态 + 赔率融合 + 置信度分级（A+/A/B/C/D）；离散度强化（极端比分预留）
- **v4.0 拆分**：剥离为 4 个独立联赛模型（韩职/瑞超/芬超/挪超）
- **v4.1~v4.4**：离散度 ×1.6→×1.8→×2.0、逆转因子 +12%→+15%、比分组合化、冷门预警、大小球动态

### 阶段 3：多联赛扩展（07-15 ~ 07-17，会话A）
- **vN.2~vN.4（挪超）**、**vS.5（瑞超）**：半场走势判定（0-0→平胜/平负 40%、领先1球→顺势 50%）、补时修正
- **v5.0**：新增赔率校验因子 + 主裁判风格因子 + 风格相克矩阵
- **vE.1（欧罗巴）** / **vB.1（巴甲）**：首回合差值、欧战经验、海拔修正、体能消耗指数
- **v6.0（里程碑）**：从"预测模型"升级为"**决策系统**"——赛前（首发/赔率急变/天气）+ 赛中（红牌/点球/补时）+ 赛后（xG/离散度）三阶段闭环

### 阶段 4：收敛与回测基准（07-17 ~ 07-21，会话A）
- **vM.KOR.2.x / vM.FIN.4.x / vM.SWE.5.x / vM.NOR.5.x**：各联赛专属规则 S 编号（如韩职 S11-S14、S24-S26）
- **v6.2**：交叉校验固化（方向→比分TOP1→半全场TOP1 一致）
- **v6.3**：**694 场全量回测基准** —— 方向 **88.4%**、比分TOP3 **87.6%**、半全场TOP3 **84.7%**（后续版本回测参照系）

### 阶段 5：规则体系编号化（07-21 ~ 07-27，会话B）
- **V6.4~V6.7→V7.0**：30 场真实数据回测；巴甲平局基线 35%；全北客场系数 -0.15；新增 **R012 对阵双源校验**；挪超逆转因子 20%

### 阶段 6：全面剔除盘口（07-26，关键转折，会话B）

## 三、六大关键转折点

1. **世界杯 → 俱乐部联赛**（07-11）：九大因子 → 泊松混合算法 + 11维度框架
2. **单联赛 → 四联赛拆分**（07-15）：韩职模型剥离出瑞超/芬超/挪超独立版本
3. **预测模型 → 决策系统**（v6.0）：加入赛前/赛中/赛后三阶段闭环
4. **⚡ 全面剔除盘口**（V9.3，07-26）：12 场实测盘口为负优化，纯模型命中率 58.3% vs 25%
5. **精简规则库、禁止单场补丁**（V9.5，07-29）：建立原则 5「不参考盘口」与原则 6「规则基于 ≥50 场数据」
6. **静态 → 动态自适应引擎**（V10.28）：规则引擎引入时间衰减、对手适应度、自动偏差回传
