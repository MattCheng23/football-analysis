## 三、查出的三处不合理

### ★发现 1｜003：比分档 1-1 ∉ 方向集且无 `*` —— **R379④ 不适用，属规则空白**
- **R379④ 只覆盖「A 级单选」**；003 是 **C 级双选**（主胜/客胜）⇒ **条文不适用**。
- 003 的 `coldRisk` 为**主胜·中等偏高**，`check_star_slot.py` 也报 WARN「无比分集冷门侧代表、亦无 C42/让位声明」。
- **现状可辩护**：003 的 logic 已写明【票面 1-1 保留说明】（方向维去平、比分维保留全场 #1 比分），该做法在二轮过审中已被接受 → 属**「有声明、无条文」**，不是静默违规。
- **待办**：把「非方向内比分档」的允许条件与声明要求**写成正式条文**（见 §五候选 1）。
- ⚠ **技术限制**：不能给 1-1 加 `*` —— `check_star_slot.py` 规则 A（C22 锚定，ERROR 级）要求「`*` 项方向 == coldRisk.dir」，而 003 的 coldRisk.dir＝**主胜**，给平局项加 `*` 会直接 ERROR。

### ★发现 2｜004 是 A 级（最高置信）却只有 51.25% 方向覆盖率
- **低于全部 C 级双选场**（68.36%–77.00%），与 C 级单选 005（51.42%）几乎相同；同为 A 级的 001 是 74.58%，**A 级内部相差 23.33pp**。
- **根因（设计事实）**：评级链度量的是**证据强度**（三正路是否齐＋有无否决），**不是结果概率**。004 证据齐（积分差 7＋状态链＋H2H 近 5 次 3 胜）但对手是防守型赫塔费 ⇒ 胜率只有 51.25%。
- **张力的实质**：「A 级＝高置信」的字面承诺是「方向可靠」，但 004 的落空面有 48.75% ⇒ 评级语义与用户直觉不符。
- **待办**：登记「A 级方向覆盖率下限」候选（见 §五候选 2），须回测。

### ★发现 3｜011：方向含平（主胜/平）但比分三档无平 —— 与 004 正好相反的错配
- 方向承诺了「平」可命中，比分却打不到任何平局项（011 三档 1-0／2-1／3-1 全为主胜）。
- **现状可辩护**：第 3 档 3-1 是 **V11.51-5-R2 打穿场（λ比 1.842≥1.8）指定档＋V11.53-8③ 总≥4 覆盖义务**；logic 已明确「控局侧**由含平覆盖 79.69% 承载**（方向维）」，并写明 1-1 让位成本 −5.47pp。
- 即：**两处不一致来自同一件事**——「方向集与比分集的关系**没有统一定义**」，各场靠 logic 散文声明兜底。
