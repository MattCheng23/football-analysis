## 一、结论（先给答案）

1. **不是特殊案例**：0-0 全量出现 **34/583 = 5.83%**，是第 6 高频比分、平局族第 2 高（次于 1-1 的 12.69%）。
2. **也不是"给少了"**：票面给出 0-0 **68 次 = 11.66%**，是它实际发生率（5.83%）的 **2.0 倍** → 给得比它出现的频率还多。
3. **真问题是"给的位置不对 + 精确率最低"**：68 次给出只中 6 次（**精确 8.8%**，常见比分里最差）、**召回 17.6%**（34 场实际 0-0 漏 28 场）。
4. **根因是泊松高估 0-0，不是条款把它挤掉**：低产带（λ和≤2.6）泊松给 0-0 **10.87%**、实际只有 **6.52%（−4.35pp，全部低分档里最大高估）**；而 1-1 泊松 12.57% / 实际 11.96%（几乎无偏）→ **平局槽默认 1-1 是实证最优，不是偷懒**。
5. **但用户观察抓到两个真缺陷**：① 平局槽单文化（票面含 1-1 的场次 60.5%、含 0-0 仅 11.7%），0-0 在结构上几乎没有位置，且唯一的 0-0 触发条款是死条款；② **0913-005 写了「降水降档」却没落到 λ**（口径自证不一致）。
