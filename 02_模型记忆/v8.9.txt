## 二、核心原则（死规定）

### 原则1：方向决定全场
- 方向"胜" → 全场主队进球 > 客队进球
- 方向"平" → 全场主队进球 = 客队进球
- 方向"负" → 全场主队进球 < 客队进球

### 原则2：比分必须匹配方向
- 方向"胜" → 比分TOP3全部为主胜比分
- 方向"平" → 比分TOP3平局比分占多数
- 方向"负" → 比分TOP3全部为客胜比分

### 原则3：半全场第二字必须匹配方向
- 方向"胜" → 第二字=胜（胜胜/平胜/负胜）
- 方向"平" → 第二字=平（胜平/平平/负平）
- 方向"负" → 第二字=负（胜负/平负/负负）

### 原则4：交叉校验强制执行
- 每次预测输出前必须执行：方向→比分TOP1→半全场TOP1三者指向同一全场结果

## 五、11维度分析框架（每场比赛默认执行）

| 维度 | 内容 |
| :---: | :--- |
| **1. 实力/级别** | 联赛强度、身价、阵容厚度、球队定位（争冠/中游/保级/鱼腩） |
| **2. 近期状态** | 近5-6场、场均进/失球、零封、半场走势 |
| **3. 历史交锋（H2H）** | 近5次、同主客、克制关系、心理优势 |
| **4. 主客场** | 主胜率、客胜率、主客进球/失球差异 |
| **5. 战意** | 保级、争冠、出线、德比、默契球（6项条件） |
| **6. 伤停与阵容** | 四关键位缺阵、伤停类型、复出状态 |
| **7. 战术与打法** | 阵型、风格、战术克制链（4条）、对位优势（4条） |
| **8. 攻防效率** | 射门、转化率、xG/xGA、定位球 |
| **9. 体能/赛程** | 一周双赛、连续客场、跨时区、赛季阶段 |
| **10. 心理/环境** | 天气、场地（天然/人工/高原）、比赛时间 |
| **11. 市场/盘口** | 初盘/即时盘、水位、同盘历史、热度判断 |


## 六、42项检查清单（核心检查项）

### 维度1：球队实力 / 联赛级别
- [ ] 联赛强度与节奏（快/慢/身体/技术）
- [ ] 球队身价、阵容总价值
- [ ] 阵容厚度（主力 vs 替补差距）
- [ ] 球队定位：争冠 / 欧战 / 中游 / 保级 / 鱼腩
- [ ] 联赛排名、积分、净胜球

### 维度2：近期状态
- [ ] 近5~6场胜负走势（连胜/连败/反弹/下滑）
- [ ] 场均进球、场均失球
- [ ] 零封次数、被零封次数
- [ ] 半场详细走势：半场胜负、半场进球/失球
- [ ] 半场领先后的最终结果（守得住吗？）
- [ ] 半场落后后的最终结果（能逆转吗？）

### 维度3：历史交锋（H2H）
- [ ] 近5次交手记录
- [ ] 同主客条件下的交手记录
- [ ] 大比分记录（是否有惨案）
- [ ] 克制关系：A队是否天生克B队（战术相克）
- [ ] 心理优势方

### 维度4：主客场表现
- [ ] 主场胜率 vs 客场胜率
- [ ] 主场场均进球/失球 vs 客场场均进球/失球
- [ ] 主场龙 / 客场虫判定
- [ ] 场地适应度（天然草/人工草）

### 维度5：战意（隐形权重最大）
- [ ] 联赛目标：争冠/欧战/保级/无欲无求
- [ ] 杯赛目标：重视/轮换/战略性放弃
- [ ] 出线形势：已出线/已淘汰/生死战/争第一/争第二
- [ ] 德比战、复仇战、恩怨战、荣誉战
- [ ] 默契球触发条件（6项）

### 维度6：伤停与阵容
- [ ] 四关键位缺阵：前锋/中场核心/中卫/门将
- [ ] 红牌停赛、累计黄牌停赛
- [ ] 伤停类型：长期重伤 / 短期伤缺 / 刚复出状态未知
- [ ] 连锁影响：关键位置缺阵导致体系崩塌
- [ ] 更衣室状态：内部矛盾、将帅失和、球员不满
- [ ] 赛前1小时首发：临场变阵、大幅轮换、意外首发/替补

### 维度7：战术与打法
- [ ] 阵型：433/4231/352/541 及稳定性
- [ ] 战术风格：控球/防反/高位逼抢/低位死守/边路传中/中路渗透
- [ ] 战术克制链（4条）
- [ ] 对位优势（4条）
- [ ] 节奏控制：快/慢、上半场猛/下半场收

### 维度8：攻防效率数据
- [ ] 场均射门、射正、射门转化率
- [ ] xG（预期进球）、xGA（预期失球）
- [ ] 关键传球、场均拦截、解围
- [ ] 定位球能力：角球数、任意球威胁、头球得分率
- [ ] 防反击能力、防定位球能力

### 维度9：体能 / 赛程 / 旅途
- [ ] 一周双赛？休息天数？
- [ ] 连续客场？长途飞行？跨时区（时差影响）？
- [ ] 上一场强度：死拼120分钟/大胜/惨败/加时赛

- [ ] 赛季阶段：赛季初状态不稳 / 中段稳定 / 赛季末战意混乱

### 维度10：心理与环境

- [ ] 场地类型：天然草/人工草/高原主场

| D | <2 | 无明显信号 |

### 分歧分析应用方式
- 高度共识 → 方向可信，可作为胆材
- 正常分歧 → 基本面优先
- 严重分歧 → 放弃低赔方向，优先考虑让球/冷门方向

### 该规则已与现有规则库融合

| 规则编号 | 规则名称 | 联动关系 |
| :---: | :--- | :--- |
| R007 | 动态条件平局 | 严重分歧时，平局概率额外+8% |
| R011 | 主胜过热抑制 | 严重分歧且主胜为低赔时，触发抑制 |
| U9 | 欧冠首回合留力 | 严重分歧时，客队+1/平局权重上升 |
| R030 | 中场核心缺阵 | 严重分歧时，缺阵方冷门概率再+15% |

## 十一、赛后复盘规则（死规定）

### 绝对禁止
1. 赛后修改比分TOP3
2. 赛后修改方向
3. 赛后调整半全场
4. 用"修正后"重新解释赛果
5. 任何形式的"赛后找补"

### 正确复盘流程
1. 核对事实：赛前预测 vs 实际赛果
2. 找出偏差：为什么没命中？哪条逻辑错了？
3. 转化为优化：将偏差总结为新规则或调整现有规则参数
4. 记录并应用：写入模型，下一轮生效
