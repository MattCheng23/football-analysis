## 一、从 ScoreCast 学到的 3 个核心优化

### 1. Dixon-Coles 低分校正（优化泊松λ计算）

**当前模型**：泊松λ = TCI × 近期状态权重 × 联赛均值 × 主场系数，未对低分比分做特殊处理。

**ScoreCast 的做法**：Dixon-Coles 模型对 0-0、1-0、0-1、1-1 这些低分比分做独立校正，因为标准泊松分布会低估这些比分的概率（尤其是0-0）。

**优化方案**：在泊松λ计算后，增加 Dixon-Coles 低分校正系数 τ：

```
P'(x,y) = P(x,y) × τ(x,y)  （当 x*y ≤ 1 时）
```

其中 τ 是经验校正系数，基于联赛历史数据拟合。各联赛低分校正系数建议：

| 联赛 | 0-0 校正 | 1-0 校正 | 0-1 校正 | 1-1 校正 |
|------|---------|---------|---------|---------|
| 韩职 | +8% | +5% | +5% | +3% |
| 挪超 | -5% | 0% | 0% | +3% |
| 芬超 | +5% | +3% | +3% | +5% |
| 巴甲 | +10% | +5% | +5% | +3% |

> 说明：平局率高的联赛（韩职32.5%、巴甲28.7%）低分校正系数更大；挪超平局率低（20.8%），0-0 反而要下调。

### 2. 指数时间衰减权重（替代固定权重）

**当前模型**：V10.28 中提到"时间衰减权重"但未落地，目前使用固定权重（近5场50%、6-15场30%、16场以上20%）。

**ScoreCast 的做法**：指数衰减，半衰期约 107 天——即 107 天前的比赛权重只有近期比赛的一半。

**优化方案**：引入指数衰减公式：

```
权重 = 2^(-(当前日期 - 比赛日期) / 半衰期)
```

建议各联赛半衰期：

| 联赛类型 | 半衰期 | 理由 |
|---------|--------|------|
| 主流联赛（挪超/瑞超/巴甲）| 90 天 | 赛季持续，状态变化较快 |
| 小联赛（芬超/韩职）| 120 天 | 数据稀疏，需要更长的记忆 |
| 杯赛（欧冠/欧罗巴/解放者杯）| 60 天 | 淘汰赛性质，近期状态更关键 |

### 3. 攻防参数最大似然估计拟合（MLE）

**当前模型**：TCI（真实战力指数）基于近10场xG差值、对手强度等手动计算。

**ScoreCast 的做法**：用最大似然估计（L-BFGS-B）从历史数据中拟合每支球队的攻防参数，使模型预测的比分分布与实际比赛结果的似然最大化。

**优化方案**：在 `football_model.py` 中增加 `fit_parameters()` 函数：

```
1. 输入：历史赛果数据（主队/客队/比分）
2. 初始化：每队攻防参数 = 0
3. 迭代优化：L-BFGS-B 最大化对数似然
4. 输出：每队攻击力α、防守力β
```

**预期效果**：从固定公式切换到数据驱动拟合，预期方向命中率提升 1-2%（基于类似项目的报告）。

## 二、优化实施计划

| 优先级 | 优化项 | 难度 | 预期提升 | 前置条件 |
|--------|--------|------|----------|----------|
| 🔴 高 | Dixon-Coles 低分校正 | 低 | 比分命中率 +2~3% | 各联赛校正系数数据 |
| 🔴 高 | 指数时间衰减 | 低 | 方向命中率 +1~2% | 无 |
| 🟡 中 | MLE 攻防参数拟合 | 中 | 方向 +1~2% | 足量历史赛果数据 |
| 🟢 低 | 蒙特卡洛模拟集成 | 高 | 比分 +3~5% | 完整模拟引擎 |

## 四、一句话总结

> **三个数学优化（Dixon-Coles低分校正、指数时间衰减、MLE参数拟合）可直接提升模型精度，其中低分校正和时间衰减无需代码改造即可在规则层面落地，MLE需代码实现。** 🎯
